The content root shared by the example content models. `full.toml`'s glossary is this page, so the example models pass the filesystem rules.

## API key
@term {aliases="API keys"}

A secret token that authenticates the Quill agent to Quill Cloud.

## Quill Server
@term {case-sensitive=true}

The self-managed Quill server.

## Agent
@term {match=marked}

The Quill process that syncs a machine's files.

An ordinary word too, so it's linked only where an author links it here.
