title: "{product} documentation"
description: Turn features on for the right users, without a deploy.
---

{product} is a feature flag service. You wrap new behavior in a feature flag, ship it turned off, and then turn it on from {cloud} or your own server: for your team first, then for a segment of users, then for everyone.

## Start here
@id: start-here

- [](getting-started.md) installs the CLI and the SDK, and creates your first flag.
- [](guides/create-flags.md) covers naming, defaults, and flag types.
- [](guides/rollouts.md) turns a flag on gradually and safely.

## Run it yourself
@id: run-it-yourself

{product} runs as {cloud}, or on your own infrastructure. To run the server yourself, see [](guides/self-hosting.md).
