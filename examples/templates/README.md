# Templates

A project that `ascribe templates eject`, with no name, gave the whole set: each type's template, its guide, and Ascribe's notes on it in `templates/`, with `templates/templates.lock` saying what they were copied from, and a type for each in `ascribe.toml`, which takes its template and guide from the lock. Each page under `docs/<type>/` began as a copy of its type's template, with every placeholder written over, so `ascribe check` has nothing to report, advice included. `crates/ascribe-cli/tests/all/check.rs` checks that, that there's a page of each type, and that the copies are still what the command writes.
