## Commands

| Command | Description | Argument | Example |
| :---- | :---- | :---- | :---- |
| `quill keys new` | Makes a signing key. | None | `quill keys new` |
| `quill keys retire` | Stops signing with a key. | The key's name, required | `quill keys retire 2025` |
| `quill publish` | Publishes a release, signed. | None | `quill publish` |
