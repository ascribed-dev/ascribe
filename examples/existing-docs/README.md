# Existing docs

A folder of plain Markdown, written before Ascribe, as the guide [Bring existing docs to Ascribe](https://ascribed-dev.com/go/existing-docs/) finds it: no `ascribe.toml`, pages with and without frontmatter, and a link written as the published site's address. `crates/ascribe-cli/tests/all/output.rs` runs `ascribe init` on a copy of it, then each step the guide takes, and holds what each prints, which the guide shows.
