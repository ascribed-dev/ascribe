- **A page that isn't listed has a Markdown version that isn't either, on Netlify.** Each build writes `_ascribe/headers.json` in the site output: the response headers each page's Markdown version needs from the host, `X-Robots-Tag: noindex` for a page that's `unlisted` and `nosnippet` for one that's `unquoted`, and a canonical `Link` to the page on every one, so a search engine lists the page and not its copy. With `headers = "netlify"` in `[consumer]`, `@ascribed/astro` writes them into the built site's `_headers`; a site with its own `public/_headers` keeps it, and the build fails with the lines it lacks. `astro dev` sends the headers with each `.md` file. On another host, a deploy step reads the list. See the [`ascribe.toml` reference](docs/content/reference/content-model.md) and the [Astro guide](docs/content/guides/astro.md).
