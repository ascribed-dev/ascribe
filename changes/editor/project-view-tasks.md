- **Build, Sync Agent Files, and Observe Examples run as tasks, from the Project view or Run Task.** Each runs the binary the project's server runs, in the terminal, in the project's folder, with `--config` when the project isn't the workspace folder. **Observe Examples** runs `ascribe observe` in the folder of a source with tested examples, after showing the commands its `ascribe.examples.toml` names and asking, each time. The task type, `ascribe`, can be named in `tasks.json`. None is offered in Restricted Mode. See [Tasks](docs/content/editor/settings.md#tasks).
