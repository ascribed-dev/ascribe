- **The editor completes, shows, and opens a link's OpenAPI operation, and fixes one that was renamed.** After a declared spec's `#`, completion offers its operations, matched on the id, the method and path, or the summary; hover shows the method and path, the summary, the tag, and deprecation; and go to definition opens the spec at the operation. The spec is read again when it changes on disk, outside the opened folder too, and a link to an id the spec lost, whose method and path now have one new operation, gets that operation as a safe fix, from the spec as it was read before or the review's base. A link to a deprecated operation is advice, `link-operation-deprecated`. See [Link to operations in the editor](docs/content/openapi/editor.md).
