- **Behavior change: Switch Project replaces the Projects view.** In a workspace with several projects, **Ascribe: Switch Project**, in the Command Palette, Pages' and Content model's title bars, and the status bar item's menu, lists every project with its folder, its server's state, and its binary, with buttons to show its output and restart it. Choosing one shows it in the sidebar and starts its server; the sidebar follows the next file of another project you open. With one project, it isn't offered. When a project's server fails to start, Pages and Content model say so, with **Show Output** and **Restart**, and in a workspace with no project, Pages says how to start one. See [the editor](docs/content/editor/index.md#switch-project).
