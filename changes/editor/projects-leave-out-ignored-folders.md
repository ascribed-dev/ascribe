- **The editor leaves folders git ignores, and build and dependency folders, out of its projects.** An `ascribe.toml` that git ignores, one in a folder such as `target`, `dist`, `vendor`, or `.venv`, and one in a source's copies (`sources/<name>/`) is no longer a project: it isn't listed in **Switch Project** and starts no language server, as when `cargo test` writes projects into `target/`. To work on one, open its folder as a workspace folder of its own. [Workspaces with several projects](docs/content/editor/settings.md) lists what's left out.
