- **The Project view switches the build, restarts its server, and opens Project Settings.** Its head has **Show Output** and **Restart** beside the server's state, a **Build** switch that moves the status bar, the preview, and the build lens with it, and, beside the project's name, a gear for Project Settings and a button for Ascribe's settings in VS Code. Its Actions are grouped as Check, Write, and Review and agents, with **Start Review** and **Prompt Agent to Fix This Project** among them, and **About**, closed at first, names the content root, the builds, the release lines, the sources, and the content types. In Restricted Mode it says Ascribe isn't running, with every action off. See [the sidebar](docs/content/editor/sidebar.md#the-project-view).
- **Behavior change: Switch Project is in the Project view's title bar, not Pages' or Content model's.** It's still in the Command Palette and the status bar's menu, in a workspace with several projects.
