- **Memo files in the editor: a lens counts them, and Add a memo writes one.** A CodeLens above a heading or a block with memos opens them, **This page** lists the memos about the heading at the cursor, and **Ascribe: Add a memo** and **Ascribe: Add a personal memo** make a memo about the section at the cursor, quoting the selection or the block. In a memo file, `about` completes and links to what it names, and the file shows its problems as you type ([memo files in the editor](docs/content/editor/actions.md#memo-files)).
