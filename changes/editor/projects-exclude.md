- **`ascribe.projects.exclude` leaves folders out of the search for projects.** A list of glob patterns, from each workspace folder, for folders whose `ascribe.toml` isn't a project, such as test fixtures: `"ascribe.projects.exclude": ["tests/**"]`. A project there isn't listed and gets no language server. Folders that `files.exclude` hides are left out too, as `node_modules` always is, and changing either setting looks for projects again. The message about the 50-project cap names the setting. See [Workspaces with several projects](docs/content/editor/settings.md#workspaces-with-several-projects).
