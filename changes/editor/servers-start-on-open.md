- **Behavior change: a change on disk no longer starts a project's language server.** With `ascribe.startServers` at its default, `onDemand`, a server starts when one of the project's files is opened, or when something asks for the project: **Switch Project**, the Project view, a command run on it, or **Check Every Build**. Before, a branch switch, a pull, a test run that rewrites fixtures, or an agent writing files could start a server for every project it touched, each running until the window closed. A project that hasn't started still shows no problems and "not checked yet"; a server already running still follows changes on disk. See [When servers start](docs/content/editor/settings.md#when-servers-start).
