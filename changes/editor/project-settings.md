- **Project Settings shows and changes the settings in `ascribe.toml`.** **Ascribe: Open Project Settings** opens a tab of the project's `ascribe.toml` settings, each with its value, its default, its description, and the line that sets it, starting with `[consumer] trailing-slash` and `base-path`. A value the file sets is changed in place, unsaved, with the file's comments kept, and the tab follows the file as it's typed and undone. See [Project Settings](docs/content/editor/settings.md#project-settings).
