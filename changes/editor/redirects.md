- **The editor shows lost addresses between checks, and the old addresses that lead to a page.** In a project that keeps its addresses, the language server compares them with the base's after a save, a change on disk, or an edit to `ascribe.addresses`: a deleted page's `address-lost` is in the Problems panel within seconds, with its fixes, and the Project view's Health counts it under Against the base, until Check Every Build replaces it. This page's About lists each old address an entry leads to the page under Also answers at. After a page's move in a project without the file, the editor offers **Keep the addresses you've published** once, which runs `ascribe addresses init` and records the move. See [Keep the addresses you've published](docs/content/publishing/redirects.md).
