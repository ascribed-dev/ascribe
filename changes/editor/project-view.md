- **A Project view heads the Ascribe sidebar, counting every build's problems while they're current.** It shows the project's language server and binary, and the problems the last **Check Every Build** found, by severity, with when it ran. A change to any file of the project marks the count out of date instead of showing it as current, and **Check Every Build** beside it checks again. See [the sidebar](docs/content/editor/sidebar.md#the-project-view).
- **Fixed:** Check Every Build goes out of date when `ascribe.nav`, a memo, or any project file changes. Before, only a change under the content root counted, so an edit to `ascribe.nav` or `ascribe.permalinks` left the status bar saying every build was checked.
