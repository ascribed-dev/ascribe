- **Apply Every Safe Fix and Format Every Page edit the whole project, from the Project view.** Each is one edit the language server makes, over the text the editor has, unsaved edits included, and the extension says how many fixes in how many files before it applies it. The files are left unsaved on purpose, to read before you save them, and Undo takes the edit back. The safe fixes are the editor build's; every build's stay `ascribe check --fix`'s. Both are in the Command Palette too. See [Edits to the whole project](docs/content/editor/sidebar.md#edits-to-the-whole-project).
