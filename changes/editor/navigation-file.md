- **`ascribe.nav` is checked and completed as you type.** Its problems appear where each is, with their fixes, and a page its section leaves out offers a quick fix that adds it to the file. Completion offers the keys, the sections the file doesn't list yet, and in `pages` the section's pages it doesn't name yet. The extension gives `ascribe.nav`, `ascribe.permalinks`, and `ascribe.lock` to the TOML language, which colors them with a TOML extension installed. See [the editor](docs/content/editor/index.md#completion).
