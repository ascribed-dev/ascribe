- **Observe Examples runs `ascribe observe` as a task, from the Project view or Run Task.** It runs in the folder of each source with tested examples, which the binary's `ascribe model` names, and `ascribe observe` lists the commands and asks in the terminal before running them. `tasks.json` names a source with `source`. It isn't offered in Restricted Mode. See [Tasks](docs/content/editor/settings.md#tasks).
