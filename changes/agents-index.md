- **`ascribe agents index` writes a compact index of your docs for your product's `AGENTS.md`.** One line a page, grouped as `llms.txt` is, held to 8 KB by leaving out descriptions before pages and saying what it left out. It prints the index, or writes it between markers in a file with `--into`, and with `--pages` copies each page's Markdown version into a folder a package can ship, with the index pointing into it. See [Index your docs for your product's agents](docs/content/guides/agents.md).
