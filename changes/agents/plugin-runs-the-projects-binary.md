- **The plugin runs the project's `ascribe` binary, as the VS Code extension does.** Its language server, stop hook, and MCP server used to run `ascribe` from the path, so a session got whatever was installed globally, not the version the project pins. They now run, in order, the binary `ASCRIBE_PATH` names, the project's `node_modules/.bin/ascribe`, and then `ascribe` on the path, through a launcher the plugin ships. See [Claude Code](docs/content/agents/claude-code.md).
