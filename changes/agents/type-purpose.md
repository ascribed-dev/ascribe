- **The rules for agents say what each page type is for.** A type's new `purpose` key, a string, says it in a few words, and `ascribe model` shows it. A type `ascribe templates eject` added says The Good Docs Project's summary of it without one, from `templates.lock`. When the rules don't fit in 4,000 characters, the page types' lines are cut first, and the cut names `ascribe model --section types` ([content model reference](docs/content/content-model/index.md), [agents guide](docs/content/agents/index.md)).
