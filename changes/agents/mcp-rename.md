- **The MCP server's `ascribe_rename` gives what `ascribe rename` changes, for an agent with no shell.** It takes a `target` and a `new` name, as the command does, and returns each changed file's whole text, the page that moves, and the entries it records in `ascribe.addresses`, writing nothing. `ascribe rename --format json` writes the same document after it renames ([ascribe rename](docs/content/command/questions.md#cli-rename)).
- **The MCP tools `ascribe_format` and `ascribe_changes` are now `ascribe_fmt` and `ascribe_diff`.** They're named for their commands. The old names are still listed, and call the new tools, for one more release ([ascribe mcp](docs/content/agents/commands.md#cli-mcp)).
