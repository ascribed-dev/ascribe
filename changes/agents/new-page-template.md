- **The `new-page` prompt starts the page from its type's template, and sends the agent to the guide.** For a type with a template, `ascribe agents prompt new-page`, the MCP server's prompt, and the plugin's `/ascribe:new-page` give the template with the title set, and the paths of the type's `guide` to read before writing. The page goes where `path` says, a file or a folder in the content root, or in the content root, named for the title; never over a file that's there. A type with no template gets its frontmatter, with each field to fill in left empty ([page templates](docs/content/guides/templates.md), [agents guide](docs/content/guides/agents.md)).
