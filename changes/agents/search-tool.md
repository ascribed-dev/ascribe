- **Agents search before they write a page, and `ascribe mcp` offers `ascribe_search`.** The tool takes the command's arguments (`query`, `paths`, `build`, `type`, `case`, `word`, `summary`, `limit`) and `project`, and returns the command's text, or with `response_format: detailed` its JSON; the server keeps each build's pages as search reads them, so a second search only scans. The rules `ascribe agents sync` writes, the skill, and the `new-page` prompt each say to search for a subject before writing a page about it, and to edit the page that covers it instead. See `docs/content/agents/commands.md`.
