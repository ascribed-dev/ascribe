- **`ascribe` installs without Node, with Homebrew or a script.** `brew install ascribed-dev/tap/ascribe`, or `curl -fsSL https://ascribed-dev.com/install.sh | sh`, which puts the release's binary in `~/.local/bin` after checking it against the release's `SHA256SUMS`, and never asks for `sudo`. On Windows, [Getting started](docs/content/getting-started.md#without-node) gives the PowerShell that downloads, checks, and installs the release's archive.
