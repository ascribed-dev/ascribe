- **Behavior change: a memo file's `about` has a grammar of its own in SPEC.md.** [SPEC.md](SPEC.md) §7.7 and its rule `about-target` say how `about` is read, where it used to point at `ascribe refs`. A path is percent-decoded, as a link's is, so a file whose name has a `#` is written with `%23` and one with a `%` with `%25`; a path that starts like an entry, such as `term:basics.md`, is written `./term:basics.md`. An empty id after `#`, a name with a space, and a path with an empty, `.`, or `..` segment are now `memo-invalid`. The editor and `ascribe rename` write an `about` the same way, so it reads back as written ([Memo files](docs/content/writing/memo-files.md)).
