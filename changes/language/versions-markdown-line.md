- **A versioned page's Markdown says which version it documents.** It opens with "Documentation for Self-managed 3.4.", the day the line's support ends, and on an older line, the current line and the address of the same page there. `versions.json` gains the target's `label`, each line's `ends`, and the archived lines with their `url`. See [What an older line says about itself](docs/content/versions/index.md#what-an-older-line-says-about-itself).
