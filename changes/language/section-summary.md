- **`@summary` gives a section a summary, which embedded help shows.** `@summary: text` under a heading gives the section its own summary, which the page doesn't show; `@summary` on the line above a paragraph makes that paragraph the summary, shown where it is. A section has one, a summary in a fragment is the summary of the section it lands in, and one inside a `@variant` arm is an error. `_ascribe/help.json`'s `summary` is the section's `@summary`, and a section without one has none; the JSON output gives a heading its section's `summary`. Each diagnostic in the diagnostics reference has a summary, the sentence saying when it's reported, so a product showing help for a diagnostic shows that. See [`@summary`](docs/content/writing/directives.md) and [Show the docs in your product](docs/content/permalinks/in-your-product.md).
