- **Behavior change: retired and aliased permalinks are kept in `ascribe.addresses`, not `ascribe.toml`.** What happened to a permalink no heading declares any more is recorded with the rest of where the docs' addresses went, keyed `go:<name>`: `[retired]` with the reason, or `[moved]` to a page and heading, or to another permalink, `go:<name>`, which makes it an alias. `ascribe.toml`'s `[permalinks]` is an error now: `ascribe addresses init` moves its entries into `ascribe.addresses` and takes the table out, and a base branch that still has it is read as if it had been moved. `ascribe permalinks retire` writes `ascribe.addresses`, and `--to` moves a name without a reason. A permalink that goes away is reported as `permalink-lost`, which was `permalink-removed`, and `ascribe.permalinks` lists a name moved to a page in a new `[moved]` table. See [docs/content/permalinks/index.md](docs/content/permalinks/index.md).
