- **A build filtered for a version older than every declared line is advice.** `build-filter-line-undeclared` reports a build whose `availability` filter names a version of a target that `[releases.<target>]` lists in no live, planned, or archived line, so `ascribe versions` doesn't know it. Declare the line in `archived`, or publish each live line with `versions = "<target>"`. Quill's example drops its `self-managed-3.3` build, since its `site` build already makes an output for each live line. See [`[builds.<name>]`](docs/content/content-model/output.md).
