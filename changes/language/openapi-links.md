- **Link a guide to an operation in your OpenAPI spec, checked against the spec.** Declare the spec in `ascribe.toml`, `[apis.<name>]` with `spec` and `reference`, and a link to it with an `operationId` as the fragment, such as `openapi.yaml#getUser`, is a link to that operation: `ascribe check` reports an id the spec doesn't have (`link-operation-missing`), with the closest ids as fixes, and each output writes the operation's address in the published reference, Redoc's or a template's, such as Stoplight Elements' or Swagger UI's. The spec can be outside the docs' folder, in the same repository. See [Link to your API reference](docs/content/openapi/index.md).
