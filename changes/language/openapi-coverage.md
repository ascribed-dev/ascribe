- **`ascribe check` says which OpenAPI operations no page links to.** Each operation of a declared spec that no link names, by its id or by its method and path, is advice, `api-operation-unreferenced`, at the API's `spec` in `ascribe.toml`; a `deprecated` operation is left out. `ascribe report inventory` counts, for each API, its operations, how many are linked, and how many have a checked example, and its JSON has them as `inventory.apis`. See [Find the operations no guide links to](docs/content/openapi/coverage.md).
