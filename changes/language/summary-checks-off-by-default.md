- **Behavior change: `summary-missing` and `summary-long` are off unless `[checks]` turns them on.** A permalink with no `@summary` was advice in every project, though only one that shows its docs in a product needs a summary. A project that ships `help.json` turns them on with `[checks] summary-missing = "warning"` and `summary-long = "advice"`; `[checks.summary-long]` with a `limit` turns `summary-long` on too. The agents' skill says to write summaries only when the check is on. [Show the docs in your product](docs/content/permalinks/in-your-product.md) has the steps.
