- **`@operation` puts an API operation's method, path, and summary in a page.** `@operation: ../api/openapi.yaml#getUser` writes `GET /users/{id}: Get a user`, linked to the operation in the published reference, with "(deprecated)" when the spec says so. Its link is checked as a link to the operation is, and one that isn't to an operation of an API `[apis]` declares is an error, `operation-link-not-operation` (ASC276). The site output writes an `<ascribe-operation>` element, which `@ascribed/elements` styles, the plain output the line, and the JSON output a block of type `operation`. See [Show an operation in a page](docs/content/openapi/operation.md).
