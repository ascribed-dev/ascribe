- **The specification describes the implicit `release` dimension.** A `[releases.<target>]` table whose target no declared dimension has makes the target a value of the dimension `release`, which `@available`, `@variant`, a page's `variant`, and a build's selection use as they use a declared one, and a declared `[dimensions.release]` takes the name instead ([SPEC.md](SPEC.md#72-declarations) §4.4 and §7.2). Ascribe already worked this way; the spec now says so.
