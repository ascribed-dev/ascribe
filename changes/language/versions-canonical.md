- **An older line's canonical address is the same page in the current line.** In a versioned build, a page of `site@3.4` names the current line's page as canonical, or the page that replaced it, following `replaces`; a page the current line has neither of keeps its own. The sitemap lists a page only when its canonical address is its own, so each current page once. See [What an older line says about itself](docs/content/versions/index.md#what-an-older-line-says-about-itself).
