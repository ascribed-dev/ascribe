- **A code example can say what it was tested with, and `ascribe check` says when it changed since.** A source's `ascribe.examples.toml` says which of its files are examples and the line of shell that tests them, and `ascribe observe`, run in the code's folder, runs it and, when it passes, records where it ran and a hash of each example in `examples.observations/default.toml`. A `@snippet` of an example the record lists as it is now gets a caption on the site, "Tested with Node 24.9.0 on Linux", from the info string's new `tested` attribute, and a line under it in the plain output. An example edited since reports `example-stale`, one no record lists reports `example-unobserved`, both advice, and a config that can't be read reports `examples-config-invalid`. A project without the file sees no change. See `docs/content/examples/tested.md`.
