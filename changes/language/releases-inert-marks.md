- **A mark that no output shows is found.** When every build that publishes a mark's content is versioned by its target, or filtered for it in the window, a mark whose versions are all at or before the oldest live line is advice, `available-same-in-every-line`, with the mark without them as a safe fix, keeping its state: `self-managed 3.1` becomes `self-managed`. Content in no live or planned line is a warning, `available-in-no-line`. A project with a badge build that isn't versioned, such as one site, gets neither, since that build shows every version. See [`[releases.<target>]`](docs/content/content-model/content.md#71-releasestarget).
