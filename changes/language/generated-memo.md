- **A problem in a generated file points at what generates it.** A top-level `@memo` that begins `Generated from` or `Generated by` says the file is generated: each problem in the file names the memo as a related place, with its text; `ascribe check --format prompt` tells the agent to change what the file is generated from and run the command again, not to edit the file; and no fix edits the file, in the editor or with `ascribe check --fix`. See [Memos](docs/content/writing/directives.md).
