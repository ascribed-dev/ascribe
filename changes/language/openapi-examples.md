- **Check a JSON example in a guide against its operation's schema in your OpenAPI spec.** Mark a `json` block with `request="openapi.yaml#createUser"` or `response="openapi.yaml#createUser 201"` in its info string, and `ascribe check` checks its JSON against that body's schema, in Swagger 2.0 and OpenAPI 3.0 to 3.2, with each disagreement an error at its place in the block (`example-schema-mismatch`): a value at the value, a property the schema doesn't allow at its key, a missing required one at its object's brace. The marker's link is checked as any link to an operation is. A marked block that isn't JSON is `example-not-json`, a body the operation doesn't have is `example-body-missing`, and a pattern or a `$ref` into another file that can't be checked is advice, `example-schema-unsupported`. See [Check a JSON example against its schema](docs/content/openapi/examples.md).
