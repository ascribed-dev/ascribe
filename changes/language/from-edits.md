- **An edit of a key `[from]` takes is made in the file that writes it.** The editor's actions, Project Settings, renames, and `ascribe permalinks retire` change a taken key in the other `ascribe.toml`, at the same path, and say which file they changed; renaming a key `take` names renames it in `take` too. `ascribe versions release` and `ascribe versions retire` run in a project that takes the releases are made in the project that writes them, and say so. `ascribe templates eject` and `ascribe vale eject` refuse a taken table, naming its file. See [the `ascribe.toml` reference](docs/content/content-model/index.md).
