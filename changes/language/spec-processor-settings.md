- **The specification says which settings and checks are Ascribe's own.** [SPEC.md](SPEC.md#72-declarations) §7.2 lists processor settings, such as `[checks]`, `[editor]`, and a type's `template`, as settings the specification doesn't define, and §4.9 says the `check` an `@intended` names is the processor's own name for it. The [diagnostics reference](docs/content/checks/diagnostics.md) marks the checks the specification doesn't define, such as `prose` and `template-placeholder-left`, as Ascribe's own instead of citing a section that doesn't define them. Nothing Ascribe reports changes.
