- **Link to an operation your OpenAPI spec gives no `operationId`, by its method and path.** `openapi.yaml#delete/users/{id}` names the `delete` operation of `/users/{id}`, is checked against the spec, and is written as Redoc 3's address for it; this form needs Redoc 3. With a template for the reference, it's an error (`link-operation-form-unsupported`), since a template has no address for an operation with no id; a link by method and path to an operation that has an id is advice (`link-operation-by-path`), with a fix that writes the id. See [Link to an operation with no id](docs/content/openapi/no-id.md).
