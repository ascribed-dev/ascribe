- **Keep the addresses you've published: a moved page records itself, and the build redirects it.** With `ascribe.addresses` beside `ascribe.toml`, made by `ascribe addresses init`, `ascribe rename` and the editor record each page they move, and `ascribe addresses move` and `retire` record a move or a removal made another way. `ascribe check` compares the addresses the docs publish with what the base published, the default branch or `--base`, and warns about one nothing accounts for (`address-lost`), with advice for a lost `#id` (`anchor-lost`). Each build writes `_ascribe/redirects.json`. See [Keep the addresses you've published](docs/content/publishing/redirects.md).
- **Behavior change: `[consumer] host = "netlify"` replaces `headers`, and writes `_redirects` too.** Each build writes Netlify's `_headers` and `_redirects` in `_ascribe/host/`, and `@ascribed/astro` places them at the site's root, keeping a site's own `public/_redirects` after Ascribe's lines. `headers` is now an unknown key whose message says to write `host`. See [the host's files](docs/content/publishing/site.md).
