- **Behavior change: `[versions] current` is removed; `[releases]` says which release is current.** Each target's current release is the newest line in `[releases.<target>] live`, and a project that sets `current` gets an error that says so (`model-versions-current`). The key shipped in 0.3.0, so a project that set it moves it: `[versions] current = "3.4"` becomes `[releases.self-managed] live = ["3.4"]`, for the target it was a release of. `availability-left-behind` compares each feature's versions with its targets' current lines, and reports nothing for a target with no list. See [`[versions]`](docs/content/content-model/content.md#7-versions).
