- **A routing setting changed is one warning, and its fix forwards every address it moved.** Changing `base-path`, `permalink-path`, `agents`, or a build's name in a project with `ascribe.addresses` is `address-lost`'s settings message, naming the change and how many addresses it moved, in place of a warning for each page. `ascribe check --fix` records the old value in `[former]`, and the build forwards every address under it, each page, Markdown version, permalink, and `llms.txt`, straight to today's, however many changes there have been. See [Keep the addresses you've published](docs/content/publishing/redirects.md).
