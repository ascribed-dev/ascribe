- **A build can publish an output for each live version of a target.** `[releases.<target>] live` lists the lines a reader can be on, such as `["3.4", "3.5"]`, and `versions = "<target>"` on a build gives one output for each: the newest, the current line, named as the build is and at its addresses, and each other as `<build>@<line>`, under its number after the base path. A line keeps what's available for the target at some version in it, and doesn't show a version at or before the oldest live line. `<output-dir>/_ascribe/versions.json` says which lines have each page, at which route. See [Versions](docs/content/versions/index.md).
