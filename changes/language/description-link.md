- **`ascribe check` reports a Markdown link in a page's description.** A description is plain text, so a link written in one is never a link: a search result and a link preview show its brackets and destination, and nothing checks it or updates it when its target moves. `description-link` (ASC198), an advice a project can set the level of, reports each one at the link, with a fix that keeps the link's text. See `docs/content/content-model/index.md` and [decision #455](project-docs/decisions/455-description-link.md).
