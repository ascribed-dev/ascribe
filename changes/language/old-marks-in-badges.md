- **Old availability marks are reported in a build that shows badges.** In a build that badges availability and isn't versioned, such as one site, a mark whose versions are all before the oldest live line, with its last state available, is now `available-same-in-every-line` advice too, with its own message: the badge is shown, and says nothing a reader of any live line needs. Its fix, the mark without the versions, is `unsafe` there, since it removes the badge; where no output shows the versions it stays `safe`. A project that keeps such badges sets `available-same-in-every-line = "off"` in `[checks]` ([docs/content/content-model/content.md](docs/content/content-model/content.md)).
