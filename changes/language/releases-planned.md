- **A version that hasn't shipped reads "planned".** A version in a line `[releases.<target>]` lists as `planned` is planned, and says so in every output: its availability reads `Self-managed (planned, 3.6)` in the site output and the plain output, the availability element's target has a `planned` attribute, the page-level `available` frontmatter and the JSON output's target have `planned: true`, and a project with `[releases]` gets each availability's `targets` in its JSON output. It stops being planned when its line moves to `live`, with no other edit. `[releases] planned-label` sets the word. See [`[releases.<target>]`](docs/content/content-model/content.md#71-releasestarget).
