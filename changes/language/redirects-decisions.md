- **Every lost address has its fixes, and `ascribe.addresses`' entries are checked.** `address-lost` offers recording git's renames, forwarding to a page like the gone one, or retiring it; `ascribe check --fix` and the editor apply them. `ascribe addresses move --from-git` records the moves git sees, and renaming a heading's `@id` records itself. Nine checks report an entry that no longer does what it says, from a value that isn't a page to a chain or the file deleted while the base has it. A retired address serves a page saying why, with a 404. See [Keep the addresses you've published](docs/content/publishing/redirects.md).
