- **An unknown key in `ascribe.toml` names the Ascribe that read it, which may be older than the project.** The message of `model-unknown-key` (ASC061) ends with the version, such as "unknown key `from` in `[ascribe.toml]`; this is ascribe 0.4.0, and the project may need a newer one", in `ascribe check`, the language server, and the MCP tools alike, and a command or tool that stops because `ascribe.toml` has errors quotes the first unknown key's message. Which keys a later version added can't be known, so the note is on every unknown key but those whose message already says where the setting went: a type's `files` and `default`, `[glossary] terms`, and `[[intended]] term`. See `docs/content/contracts/content-model/validation.md` and [decision #849](project-docs/decisions/849-unknown-key-version.md).
