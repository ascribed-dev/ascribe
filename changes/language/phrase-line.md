- **A phrase can be a target's current line.** In `[phrases]`, `release = { line = "self-managed" }` makes `{release}` the newest live line of `[releases.self-managed]`, as the list writes it, so a version a page names follows the list with no value kept by hand. A target with no live line is an error, `model-phrase-line`. See [`[phrases]`](docs/content/content-model/content.md#phrases).
