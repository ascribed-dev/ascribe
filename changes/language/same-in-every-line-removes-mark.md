- **`available-same-in-every-line` removes a mark that would say nothing.** When the mark without its versions would be its target alone, generally available, and the target is the only value of its dimension, as `ascribe 0.4.0` in a project with one product, the fix removes the `@available` line, the page's `available` key, or the row's `{available=…}` instead of writing `ascribe`, which a badge build showed as "Available: Ascribe (GA)". A project with another value in the dimension, a build filtered for another target, a mark inside one that says something, and a fragment's mark keep the rewrite. See [the release targets](docs/content/content-model/content.md).
