- **Code blocks have a copy button.** `@ascribed/elements` adds a button to each code block on a page, including one with a title or a tested line, and one in a tab, that copies the code alone and says "Copied" to a screen reader. With scripts off there's none. A site turns it off with `--ascribe-copy-display: none`, restyles it with the `--ascribe-copy-*` properties, and translates its words in CSS ([element library reference](docs/content/astro/elements.md#copy-buttons)).
