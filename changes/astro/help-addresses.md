- **`@ascribed/astro` serves each permalink's help entry as JSON, for each live line.** A product fetches its own line's at `<permalink-path><name>.json`, such as `/docs/go/connect.json`, or `/docs/3.4/go/connect.json` for an older line, and falls back to the copy of `_ascribe/help.json` it bundled. The build's `_ascribe/headers.json` gives each address `Access-Control-Allow-Origin: *`, so a product on another origin can read it ([Show the docs in your product](docs/content/permalinks/in-your-product.md)).
