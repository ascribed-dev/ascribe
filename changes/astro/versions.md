- **`@ascribed/astro` serves every line of a versioned build from one site.** The collection has every live line's pages, an older line's with its number in front of their ids, and each entry's data has `line` and `current`. `@ascribed/astro/Versions.astro` lists the lines that have a page, `sidebar(nav, entries, { entry })` shows the entry's line, and `astro dev` rebuilds every line. A permalink forwards to the current line, and only the current line's Markdown and `llms.txt` are published. See [Versions](docs/content/versions/index.md#publish-with-astro).
