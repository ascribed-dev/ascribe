- **The docs have an Install page, and getting started has one path.** [Install](docs/content/install.md) has every way to install `ascribe`: npm, Homebrew, the install script, PowerShell, and a release's archive, with which `ascribe` runs when a machine has several. [Getting started](docs/content/getting-started.md) installs with npm and starts with `ascribe init`, without the branch for writing `ascribe.toml` by hand, and its CI recipe is [Checks in CI](docs/content/checks/ci.md).
