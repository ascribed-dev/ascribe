- **`ascribe check` reports two pages of a build with the same description (`description-duplicate`).** Each is reported at its description, naming the others, since a search result, a link preview, and `llms.txt` would say the same of both. It's advice, beside `title-duplicate`, and a project can raise it or turn it off in `[checks]`. See [the diagnostics reference](docs/content/reference/diagnostics.md).
