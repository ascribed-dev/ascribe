- **A page can say it isn't listed, and each build writes its page records.** A page's frontmatter `listing` is `listed`, `unquoted`, or `unlisted`; an `unlisted` page is still built, and is left out of `llms.txt`. Each build's site output holds `_ascribe/pages.json`: a record of every page, with its route, source, title, description, canonical address, `listing`, and Markdown version, and the project's own `robots.txt` lines from the new `[crawlers] lines`, with the base path put before each `Allow` and `Disallow` path. `ascribe check` advises when a page that isn't listed is at an address those lines disallow for every crawler (`listing-disallowed`), since the crawler can't read that it isn't to be listed. See the [`ascribe.toml` reference](docs/content/reference/content-model.md) and the [output-layout contract](docs/content/contracts/output-layout.md).
