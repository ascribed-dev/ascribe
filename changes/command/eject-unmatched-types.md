- **`ascribe templates eject` says when a type it added matches no page yet.** It then lists the pages of the default type, which are the ones to name in the new type's `files`. A type it adds also declares `title` and `description` as the default type does, `inline` and `role` with them, when they're strings there. The JSON gains `pages` and `copied` on each type added, and `default_type` and `default_pages`. See [the command reference](docs/content/reference/cli/sources.md).
