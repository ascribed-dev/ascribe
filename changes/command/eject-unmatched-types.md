- **`ascribe templates eject` says when a type it added matches no page yet.** It then lists the pages that name no type yet, the ones to give `type:`. A type it adds also declares `title` and `description` as the type `page` does, `inline` and `role` with them, when they're strings there. The JSON gains `copied` on each type added, and `untyped`. See [the command reference](docs/content/reference/cli/sources.md).
