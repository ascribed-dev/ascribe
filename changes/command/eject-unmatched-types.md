- **`ascribe templates eject` lists the pages that don't name a type yet.** They're the ones to give `type:`. A type it adds also declares `title` and `description` as the project's first type to declare them does, `inline` and `role` with them, when they're strings there. The JSON gains `copied` on each type added, and `untyped`. See [the command reference](docs/content/reference/cli/sources.md).
