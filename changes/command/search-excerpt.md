- **`ascribe search` cuts a long block to its match, in JSON and over MCP too.** A place's `text` is at most about 240 characters around the match's first character, with `…` where it's cut, so a code block or a table row that has the words somewhere in it no longer comes back whole: in the docs, `ascribe search "fail on warnings in CI"` printed 20 KB, 15 KB of it one generated JSON Schema, and prints about 500 bytes now. `line` and `column` still say where the match's first word is, within the block, and `match` ends where `text` is cut when the match runs past it. The text output's 80-character excerpt no longer stretches to a match's last word either, and neither does the editor's search view. See `docs/content/command/questions.md`.
