- **`ascribe search` finds words as readers read them, and names the line to edit.** It reads each page as every build publishes it, phrases filled in, so `ascribe search '"sign in to quill cloud"'` finds the line that says `Sign in to {cloud}`, says it reads through the phrase `cloud`, and names the heading and the arm it's under. A match wholly inside a phrase's value is at the phrase's line in `ascribe.toml`. See `docs/content/command/questions.md`.
