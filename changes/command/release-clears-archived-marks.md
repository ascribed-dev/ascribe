- **`ascribe versions release` removes the marks of the line it archives.** Where no build is versioned by the target, the release moves the old current line to `archived`, and each mark naming a version in it then says nothing: every line left has what it marks. The release now removes or rewrites each one `available-same-in-every-line` would report, as its fix does, along with a feature's spec, and lists them; `--dry-run` lists them without writing. The JSON lists them as `cleared` and `cleared_features` ([`ascribe versions release`](docs/content/versions/release.md)).
