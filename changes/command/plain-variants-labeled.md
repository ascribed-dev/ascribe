- **Behavior change: the Markdown version of a page says a switcher is one, and heads each of its arms.** A variant group a build keeps more than one arm of, which the site shows as tabs, now opens with a line saying a reader sees one of its arms at a time, and by what: `A reader sees one of the next 3 sections at a time, chosen by package manager.` Each arm is under a heading one level below its section that names the dimension and the value, `### Package manager: pnpm`, or its title, instead of a bold label, so an agent reading a page knows the arms are alternatives and which is which. `ascribe render` prints the same text, and its JSON's `text` has it too; the HTML comment it wrote above a switcher is gone. A build that leaves one arm is unchanged. See the [variants guide](docs/content/guides/variants.md) and the [`ascribe render` reference](docs/content/reference/cli.md).
