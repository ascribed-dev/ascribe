- **`ascribe refs` takes an image, and lists the files that show it, link to it, or name it.** `ascribe refs images/keys.png` lists each place as `image`, `link`, `html` (raw HTML such as `<img src>`), or `frontmatter` (a field such as `cover`), the uses `image-unused` reads, and an image nothing uses answers with no places and exit code `0`. A file that's neither a page, a fragment, nor an image says what `refs` takes, instead of that it doesn't exist. The MCP server's `ascribe_refs` takes an image too. See `docs/content/command/questions.md`.
