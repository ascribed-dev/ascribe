- **`ascribe refs release:<target>@<version>` lists the marks that name a version in one release line.** `ascribe refs release:ascribe@0.4.0` finds each availability spec that names a version in that line of `[releases.ascribe]`, a history's steps and `planned` included, where a text search or `dimension:release` couldn't say which release a mark was for. Every `availability` place `refs` lists now shows its spec as written, after the use in text and as `spec` in JSON, which is null for every other use. The `ascribe_refs` tool takes the same target. See [`ascribe refs`](docs/content/command/questions.md).
