- **`ascribe --help` lists the commands in groups, with short descriptions.** The commands are under four headings, for the kind of work each does: writing and checking, asking about the project, keeping records, and connecting tools. Each description is a line of about twelve words, and a command's own `--help` says the rest. The note for agents moved to `ascribe agents --help`, and `ascribe --help` points there. The [command reference](docs/content/command/index.md)'s synopsis lists the commands in the same groups.
