- **`ascribe versions retire` takes the oldest live line out of the source once its archive is hosted.** `ascribe versions retire "self-managed 3.4" --url https://archive.example.com/3.4/` moves the line to `archived` with its address and the day it ended, rewrites each mark for its target to the simplest spec that means the same in every line still live, and proves no live line's output changed. It lists what no line has any more, and deletes it only with `--remove-unused`, and it lists where each of the line's addresses should go, for a host's redirects. `ascribe build` no longer writes an archived line's output, and removes the folder it wrote before. See [Retire a line](docs/content/versions/index.md#retire-a-line).
