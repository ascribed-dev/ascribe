- **`ascribe report links` doesn't ask again about an address that answered.** An address that answered with nothing to report is kept in `.ascribe/cache/links/`, with the day, and isn't asked about again for up to `[checks.links] reuse-days`, 14 days unless set; `0` asks about every address on every run, and `--recheck` asks about every address once. A link that moved, failed, or timed out is asked about on every run, so every problem in a report was found in that run. The report says what it did, `Checked 1786 addresses: asked about 64, and reused 1722 answers, the oldest from 28 September.`, and its JSON's `links` gains `asked`, `reused`, and `oldest_answer`, with `checked` their sum and `schema_version` still `1`. The scheduled job in [The project report](docs/content/guides/report.md#on-a-schedule) keeps the answers with `actions/cache` and runs daily. Deleting `.ascribe/` costs time and nothing else.
