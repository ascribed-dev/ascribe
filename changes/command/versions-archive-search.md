- **An archive can be searched, from a folder opened from a disk.** `ascribe versions archive` writes a search box at the top of every page's sidebar, which finds pages and headings by their words, best first: a page's title, then a heading, then the text under one, code blocks included. Its index is `search-index.js`, loaded the first time the box is used, and the command says its size. Nothing is fetched from anywhere else, and with scripts off the box is absent. See [Archive a line](docs/content/versions/index.md#archive-a-line) and the [archive contract](docs/content/contracts/archive.md).
