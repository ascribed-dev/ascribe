- **`ascribe model` shows every section of `ascribe.toml`, each key with the value in effect.** `--section` takes `project`, `consumer`, `editor`, `checks`, `crawlers`, `listing`, and `permalinks`, and the MCP tool's `section` with it; each key is shown with its value, the default where the file leaves it out. The JSON has each section, and the text without `--section` names them at its end, still within 4,000 characters. The keys and defaults come from the registry the loader reads. See `docs/content/command/questions.md`.
