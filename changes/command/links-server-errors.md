- **`ascribe report links` asks again about a link whose server answered with an error.** An address that answers with a `5xx` status is asked about a second time after 30 seconds, on every run, and only that answer counts, so a server's passing failure isn't reported. One that fails again is still reported, as `link-external-broken`, with a message that says the server failed, which may be temporary, instead of that the link is broken for readers. A `404` or a `410` is asked about once and reported as before. `ASCRIBE_LINKS_RETRY_WAIT` sets the wait in seconds. See [Check external links](docs/content/checks/external-links.md).
