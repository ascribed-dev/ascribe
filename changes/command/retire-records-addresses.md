- **`ascribe versions retire` records the line's addresses in `ascribe.addresses`.** In a project that keeps the file, each address the retired line published that goes to a page in the current line is recorded in `[moved]`, keyed by the address, so the build writes its redirect and `ascribe addresses list` shows it. Addresses that go to the archive are still the host's to redirect. `ascribe check --base` no longer reports `addresses-build-gone` for a line `[releases]` archives. The JSON has `recorded`. See [Archive and retire a line](docs/content/versions/archive.md).
