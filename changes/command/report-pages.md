- **`ascribe report pages` lists every page's record.** For each build, every page it publishes, sorted by address, with its title, description, and listing, and where the listing comes from: as a table cut at `--limit`, or as JSON whose records have the fields of the site output's `_ascribe/pages.json`. `--not-listed` lists only the pages kept out of search, and why. It reads nothing a build hasn't worked out, so it needs no network. See [the project report](docs/content/guides/report.md).
