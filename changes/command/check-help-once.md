- **`ascribe check` prints a code's shared help once.** In text output, the first diagnostic with a code prints its help in full, and later ones with the same help point back to it, as `Help: as for ASC252 above (ascribe explain ASC252)`. Help that names the occurrence, such as a fix that links to a likely page, is still printed every time. The concise, JSON, and prompt formats are unchanged. See `docs/content/checks/check.md`.
