- **`ascribe search` finds a fragment's text, a snippet's code, and a page's title and description.** A line of a fragment is one place however many pages include it, with the pages that show it: the first three, each with the heading it's under, then the `ascribe refs` command for the rest. A match in a snippet's code is at the code file's line, `through code:<file>#<region>`. A page's title and its description are at their keys in the frontmatter, and titles come first. See `docs/content/command/questions.md`.
