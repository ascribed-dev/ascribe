- **`ascribe resolve go:<name>` shows the help a product shows for a permalink.** It prints the permalink's title, summary, text, and address, as the build's `_ascribe/help.json` has them, and `--format json` prints the entry as the file writes it, with `version`, `build`, and `line`. A name the build doesn't publish exits with `1` and names the closest; a retired one gives its reason. The `ascribe_resolve` tool takes the same `go:<name>`, and the rules `ascribe agents sync` writes say an agent can read a permalink's help with it. See [`ascribe resolve`](docs/content/command/questions.md) and [Show the docs in your product](docs/content/permalinks/in-your-product.md).
