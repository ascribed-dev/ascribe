- **Behavior change: `ascribe render` is now `ascribe resolve`, and its MCP tool is `ascribe_resolve`.** It takes the same arguments and options, and writes the same output and exit codes: a page resolved for one build, written as the build's plain Markdown output. Its JSON's schema is `schemas/resolve.schema.json`, still at `schema_version` 1 with every field as it was. There's no alias: `ascribe render` is an unknown command, and `ascribe_render` an unknown tool. Agent files and skills written by `ascribe agents sync` before this release name the old command until it runs again. See `docs/content/command/questions.md`.
