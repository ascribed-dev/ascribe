- **`ascribe resolve --emit site` writes a page as the site output does.** Markdown with Ascribe's elements, tabs, notes, and availability badges, as `ascribe build --emit site` writes the page's file and `@ascribed/astro` receives it, without building the project. `--frontmatter` adds the site output's frontmatter, with its `formatted`, `available`, and `source` keys; a line of a versioned build writes the line's links. `--emit plain` is the default, and the JSON's new `emit` says which output `text` is. See [`ascribe resolve`](docs/content/command/questions.md).
