- **`ascribe templates status` says what's changed in the templates since the project's copy.** For each template a project took, it says whether the set this `ascribe` carries has changed it since the copy, with the sections that differ, and whether the project has changed its copy, telling the two apart by the hashes in `templates.lock`; then each template the project doesn't have. Without a lock or an entry it says so, and compares the files with the set alone. It reads no network and changes no file. `--diff <NAME>` prints the change to one template, `--exit-code` exits with 1 when the set has changed one, and `--format json` has a schema. See `docs/content/reference/cli/sources.md`.
