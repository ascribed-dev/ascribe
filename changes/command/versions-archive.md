- **`ascribe versions archive` renders a line into a folder of HTML that needs nothing else.** `ascribe versions archive "self-managed 3.4" --to archive/3.4` writes every page of the line with a statement of what it is, a sidebar, a contents page, `all.html` to print the whole line, and `noindex` on every page, with no script, working from a disk with no server. It writes nothing into the project, and says what to add to `[releases]` once the folder is hosted. See [Archive a line](docs/content/versions/index.md#archive-a-line) and the [archive contract](docs/content/contracts/archive.md).
