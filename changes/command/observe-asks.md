- **`ascribe observe` asks before it runs the commands, when its input is a terminal.** It lists the `test` and `[environment]` commands of `ascribe.examples.toml`, asks **Run them? [y/N]**, and runs nothing, and writes nothing, unless the answer is yes; then it exits 2. `--yes` skips the question. In CI or a hook, where standard input isn't a terminal, it runs them as before, without asking. See [`ascribe observe`](docs/content/examples/sources.md#cli-observe).
