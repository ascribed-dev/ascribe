- **Check one rule at a time.** `ascribe check --code ASC037` (or `--code link-id-missing`, repeatable) shows only the problems with that code, across the whole project, so a rule can be fixed everywhere instead of file by file. The counts, the exit code, `--format prompt`, and `--fix` are about what's shown, and the concise list's "and N more" command keeps the filter. `--summary` ends with the command for the code it counts most. The MCP tool `ascribe_check` takes `code`. See [Checking one rule at a time](docs/content/reference/cli/check.md#checking-one-rule-at-a-time).
