- **`ascribe templates eject --keep-type` takes a template for a type the project declares.** It writes the template, its guide, Ascribe's notes, and `templates.lock` as `eject` does, and adds only `template` and `guide` to the type, leaving its `files`, frontmatter, other keys, and comments as they are. It refuses a type whose frontmatter doesn't declare the template's fields as strings. Without the flag, `eject`'s refusal of a declared type names it. See [the command reference](docs/content/reference/cli/sources.md).
