- **`ascribe init` starts a project, writing its first `ascribe.toml`.** In a folder with no `ascribe.toml` at or above it, it writes a small, commented one, with a default `page` type, and makes `docs/`; `--templates` takes the six page templates too, as `ascribe templates eject` does. Where there's a project, it names it and writes nothing. `ascribe templates eject` without a project now says to run it. See `docs/content/reference/cli/sources.md`.
