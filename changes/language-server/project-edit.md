- **`ascribe/projectEdit` answers with one edit for the whole project.** Its `kind` is `fixAll`, every safe fix of the problems the server shows, in every source file, or `format`, every source file as `ascribe fmt` formats it. The edit is to the text the server has, each open document's naming its version, with how many files it changes and how many problems it fixes. See [the language server's README](crates/ascribe-lsp/README.md).
