- **Apply a page's safe fixes in one action, or on save.** **Source Action… → Apply the safe fixes in this page** (`source.fixAll.ascribe`) applies every safe fix of the problems the editor shows in the page, settled as `ascribe check --fix` settles them; with `editor.codeActionsOnSave` it runs on save.
