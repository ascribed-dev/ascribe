- **`@operation`'s link completes, hovers, and opens as a link to an operation does.** After the spec's `#` in an `@operation`, the editor offers the spec's operations; hover shows the operation's method, path, summary, tag, and deprecation; go to definition opens the spec at it; and when the spec changes on disk, the line is checked again, so an operation the spec renamed gets the safe fix. See [Show an operation in a page](docs/content/openapi/operation.md#operation-editor).
