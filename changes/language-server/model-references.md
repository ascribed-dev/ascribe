- **Find All References works on a content model entry in `ascribe.toml`.** On a phrase's key, or the table header of a feature, glossary term, dimension, note type, or widget, it lists the places that use it, as on a use in a page. `ascribe/inventory` also lists page content types, with how many pages each has, and each dimension's values. See [the language server](crates/ascribe-lsp/README.md#the-projects-inventory-ascribeinventory).
