- **The editor checks every line of a versioned editor build, and says which lines a problem is in.** A problem only some lines have ends "(only in build `site@3.4`)". A hover on a mark's version says which line it falls in, a hover on `replaces` says which page each line publishes, and Go to Definition on `replaces` opens the replaced page. `ascribe/targets` and `ascribe/preview` list each build's lines. See [The editor](docs/content/editor/index.md#hover).
