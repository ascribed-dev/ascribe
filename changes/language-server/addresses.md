- **`ascribe/addresses` says what comparing the addresses with the base's found.** The server keeps the base's addresses for each base commit and version of Ascribe, and compares them after a load, a save, a change on disk, or an edit to `ascribe.addresses`, never as a page is typed: the notification has the file, the base, the count of pages lost, and the problems at the file, as `ascribe check` reports them. The `ascribe/page` answer's `about.alsoAnswersAt` lists the old addresses an entry leads to the page. See [Keep the addresses you've published](docs/content/publishing/redirects.md).
