- **The language server reads memo files.** It checks the memo files in `memos/` and `.ascribe/memos/` as they change, completes and links their `about`, shows a CodeLens on what they're about, lists them in `ascribe/page`'s `memos`, and writes one with the `ascribe/edit` actions `addMemo` and `addPersonalMemo` ([memo files in the editor](docs/content/editor/index.md#memo-files)).
