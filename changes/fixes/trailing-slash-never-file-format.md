- **Fixed:** with `trailing-slash = "never"`, an Astro site serves each page at its address, not a redirect. `@ascribed/astro` left Astro's `build.format` at `"directory"`, so each page was written as `x/index.html`, which a static host such as Netlify serves at `x/`: the address in every link, the sitemap, and the canonical answered with a 301. With `"never"`, the integration now gives Astro `build.format: "file"`, so a page is `x.html`, and a `build.format` that disagrees with `trailing-slash` fails the build ([the Astro reference](docs/content/astro/reference.md)).
