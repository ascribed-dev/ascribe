- **Fixed:** A build in a source's folder no longer keeps the language server busy. Since VS Code started telling each server about its sources' folders wherever they are, a source such as `path = ".."` sent it every file a build wrote, such as `target/`, and each one asked for every lens again. VS Code now tells the server only of the files a source's `include` and `ignore` patterns read, and its `ascribe.examples.toml` and observations, and the server asks for the lenses again only for those ([docs/content/editor/writing.md](docs/content/editor/writing.md#code-files-a-page-shows)).
