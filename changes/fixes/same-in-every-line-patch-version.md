- **Fixed:** `available-same-in-every-line` no longer reports a patch version inside the oldest line. With `live = ["3.4", "3.5"]`, `self-managed 3.4.2` was reported as shown by no output, with a safe fix to write `self-managed`, though the 3.4 and 3.5 lines' outputs show "3.4.2". The check now decides what's hidden the way a line's output does, so only a version at or before the oldest line, such as `3.4` or `3.3`, is reported ([docs/content/versions/index.md](docs/content/versions/index.md)).
