- **Fixed:** typing in a fragment is as fast in the editor as it was before 0.4.0. Since `replaces`, each page the language server resolved on its own read every page's frontmatter to look for one, so a keystroke in a fragment many pages include read the whole project once for each of them. A page now looks only when it has a `replaces` of its own. In a project of 3,000 pages, a keystroke in a fragment 30 pages include takes about a third of the time, and opening the project is faster too.
