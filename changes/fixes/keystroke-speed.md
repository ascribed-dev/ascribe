- **Fixed:** the language server answers a keystroke in a large project faster again. Since 0.4.0, resolving each page an edit reaches looked through every file of the project for glossary terms no glossary page shows; and since 0.4.2, each round of checks matched every file's problems against `ascribe.baseline` even when the project has none.
