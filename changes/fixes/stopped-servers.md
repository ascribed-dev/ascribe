- **Fixed:** A project whose folder is deleted takes its server and problems with it. Deleting a folder, as removing a git worktree does, is reported as the folder alone, so the extension missed the `ascribe.toml` inside it, and kept that project's server running and its problems in the Problems panel; now it stops the server, which clears them ([Workspaces with several projects](docs/content/editor/settings.md)).
- **Fixed:** A language server that doesn't stop when asked is killed, with any process it started. The editor left it running after "Stopping server timed out", and a server whose window had closed could run on for days; now it's killed when its stop times out, and every server still running is killed as the window closes ([Workspaces with several projects](docs/content/editor/settings.md)).
