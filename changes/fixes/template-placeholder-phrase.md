- **Fixed:** a phrase or code with a placeholder's name isn't reported as the template's placeholder. On a page of a type with a template, `template-placeholder-left` reported a phrase such as `{product}`, which the tutorial's notes tell a writer to use, and a placeholder quoted in inline code. Only a placeholder whose brace is still escaped, as the template writes it, is reported now ([the templates guide](docs/content/templates/index.md)).
