- **Fixed:** the language server no longer uses a third of a core while a build writes in the project. Each file the editor's watcher reported, such as a build's output, a dev server's cache, or an image, ran the checks across the project again, about 37 ms on a project of 240 pages. They now run again only when the change reaches what the project reads: a page, a fragment, a file a page uses that appears or goes, or a memo.
