- **Fixed:** **Ascribe: Add a memo** names its file within the file system's limit. The name was the quote's first five words, which in prose without spaces, such as Chinese or Japanese, could be over the 255 bytes a file name can have, and the editor then said the page had changed. The name is cut to 100 bytes now, and when a memo file can't be written, the message says what the file system said ([docs/content/editor/actions.md](docs/content/editor/actions.md#memo-files)).
