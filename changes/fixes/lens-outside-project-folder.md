- **Fixed:** VS Code moves the "Shown in N pages" lens when a file outside the project's folder is saved. A source whose folder is beside the project, such as `path = ".."` or one another project shares, kept its lens where the region was, and This page's tested-example rows kept a source's old observations, because the editor didn't tell the language server those files changed. It now tells each server about its sources' folders, wherever they are ([docs/content/editor/index.md](docs/content/editor/index.md#code-files-a-page-shows)).
