- **Fixed:** review no longer shows a tested example's snippet as changed when it isn't. With a source outside the project folder whose `include` doesn't reach its root, `ascribe diff` read the base from git without the source's `ascribe.examples.toml` and `examples.observations/`, so at the base no snippet was a tested example, and every one read as changed. On Ascribe's own docs, a clean branch reported 15 changed pages. The base now has both files, and the editor's review and the HTML report, which read it the same way, show only real changes. See `docs/content/review/diff.md`.
