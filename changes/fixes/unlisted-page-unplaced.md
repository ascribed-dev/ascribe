- **Fixed:** an `unlisted` page is no longer reported as unplaced in the navigation. A page that's `listing: unlisted` is in no sidebar, so a section's `pages` in `ascribe.nav` leaving it out isn't `nav-page-unplaced` advice any more, and `ascribe check --fix` and the agents' hook no longer add it there. The editor's Pages view marks it **unlisted** instead of **not placed**, and Place Here refuses it ([the navigation](docs/content/navigation/index.md)).
