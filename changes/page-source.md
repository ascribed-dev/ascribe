- **A page in the site output says where its source is.** Every page's frontmatter has `source`, its path from the content root, such as `guides/install.md`, and the generated schema types it, so a layout's "Edit this page" link is `entry.data.source` after the repository's address and the content root's folder, whatever the build folder's path. **Behavior change:** `source` is reserved on page types, as `formatted` is, so a content type that declares a field named `source` fails with `model-field-reserved`; rename the field. See the [Astro guide](docs/content/guides/astro.md).
