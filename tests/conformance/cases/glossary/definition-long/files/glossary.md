## Region
@term

The place a project's data is kept and served from, chosen when the project is created. Each region has its own address, its own limits, and its own price, and a project's members reach it from anywhere, though requests from far away take longer. Moving a project to another region means exporting it, then importing it.

A second paragraph can be as long as it needs to be, since only the first is the definition that a link's title and a hover show.

## Backup region
@term

A second region that holds a copy of a project's backups, so that the project can be restored if its own region is lost. It's chosen in the project's settings, must differ from the project's own region, and is billed for the storage its copies use, not for the requests it serves.
