---
description: "Check the project, fix what's reported, and check again."
argument-hint: "[path]"
---

Run `ascribe agents prompt fix [--arg path=<path>]`, and do what the prompt it prints asks.

Take the arguments from this, in this order, and leave out an optional one that isn't given: $ARGUMENTS

- `path`: A file or folder to fix; by default, the project at or above the current directory.

Without a shell, use the prompt `fix` of Ascribe's MCP server instead.
