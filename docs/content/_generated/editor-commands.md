| Command | What it does |
|---|---|
| **Ascribe: Open Page Preview to the Side** | Opens the page preview of the active page beside the editor, starting its project's server if it hasn't started. |
| **Ascribe: Open Page Preview** | Opens the page preview of the active page in place of the editor, starting its project's server if it hasn't started. |
| **Ascribe: Open Site Preview** | Opens the active page on its project's dev server, in the browser. See [Site preview](../editor/preview.md#site-preview). |
| **Ascribe: Select Preview Build** | Picks the build the preview shows, for the previewed page's project, as the preview's **Build** picker does. It's the same choice as **Switch Build**. |
| **Ascribe: Prompt Agent to Fix This File** | Builds a prompt for your agent about the active file's problems, and puts it where `ascribe.agents.promptTarget` says, without sending it. Shown when the file has problems. See [Prompt your agent](../agents/prompts.md). |
| **Ascribe: Prompt Agent to Fix This Project** | Builds a prompt for your agent about the problems of the active file's project, as Prompt Agent to Fix This File does. Shown when the project has problems. |
| **Ascribe: New Page** | Starts a page from its type's template: asks for the type, each with what it's for, then the title, makes the page in the content root, and opens it with the first thing to fill in selected; the page names its type in its frontmatter. Run on a folder in the Explorer, it makes the page in that folder. It's in the Pages view's title bar too. See [Start a page](../editor/actions.md#start-a-page). |
| **Ascribe: Actions for the Cursor** | Opens the [actions bar](../editor/actions.md#the-actions-bar): the fixes for problems at the cursor, then the actions that apply to the cursor or selection. |
| **Ascribe: Go to Next Placeholder** | Selects the next thing the page's template left to fill in, after the cursor, so typing replaces it; after the last, it goes back to the first. |
| **Ascribe:** *an action* | Runs the action, such as **Ascribe: Wrap in a note**, in a Markdown file of a project. Each of the [actions](../editor/actions.md) is a command. |
| **Ascribe: Switch Build** | Picks the build you're looking at in the active file's project: the one the preview renders and the status bar names. Choosing the editor build follows `[editor] build`. See [The status bar](../editor/preview.md#the-status-bar). |
| **Ascribe: Check Every Build** | Runs `ascribe check` over every build of the active file's project, and adds to the Problems panel the problems of builds other than the editor's, which the language server doesn't check. When no file of a project is active and the workspace has several projects, it asks which. See [The Problems panel](../editor/settings.md#the-problems-panel). |
| **Ascribe: Search Pages as Readers See Them** {available=next} | Finds words as readers read the active file's project's pages, as you type, unsaved text included, and opens the line that wrote the place you choose. It searches the build the status bar names; its **Search Every Build** button searches every build. See [Search](../editor/writing.md#search). |
| **Ascribe: Apply Every Safe Fix** {available=next} | Applies, as one edit, every safe fix of the problems the editor shows in the active file's project, the editor build's, after saying how many fixes in how many files. The files are left unsaved, for you to read before you save them, and Undo takes the edit back. When no file of a project is active and the workspace has several projects, it asks which. See [Edits to the whole project](../editor/sidebar.md#edits-to-the-whole-project). |
| **Ascribe: Format Every Page** {available=next} | Formats every page and fragment of the active file's project as `ascribe fmt` does, as one edit, after saying how many files it changes. The files are left unsaved, for you to read before you save them, and Undo takes the edit back. When no file of a project is active and the workspace has several projects, it asks which. See [Edits to the whole project](../editor/sidebar.md#edits-to-the-whole-project). |
| **Ascribe: Project Menu** | Shows the menu of the active file's project, as clicking its status bar item does: switch the build, check every build, show the server's output, switch project, restart its server, dim what the build leaves out, or open the preview. |
| **Ascribe: Dim What the Build Leaves Out** | Turns the build lens on or off for the active file's project: the editor dims what the build you're looking at leaves out of each page, with a hover that says why. See [The build lens](../editor/preview.md#the-build-lens). |
| **Ascribe: Start Review** | Marks what changed in the preview, against a base it asks for, for the active page's project. Its server must be running: open one of its pages first. See [Review in the preview](../editor/review.md). |
| **Ascribe: Stop Review** | Turns review off for the active page's project, and frees its base. |
| **Ascribe: Changed Pages** | Lists the pages the change touches in the preview's build; choosing one opens it and its preview. |
| **Ascribe: Refresh Comments** | Reads the pull request's review threads from GitHub again, for the active page's project. See [Comments in the preview](../editor/review.md#comments-in-the-preview). |
| **Ascribe: Submit Review…** {available="ascribe 0.4.0"} | Opens the preview's dialog for submitting your review's comments, on the page it shows or the first changed page. Shown while you have comments to submit. It's in the Review view's title bar too. |
| **Ascribe: Open Source Changes** {available="ascribe 0.4.0"} | Opens one diff of the changed pages' source files, at the base against the working tree: each page's own file, and the fragments and pages it changed through. It's in the Review view's title bar too. See [The Review view](../editor/review.md#the-review-view). |
| **Ascribe: Open Project Settings** {available=next} | Opens Project Settings for the active file's project: its `ascribe.toml` settings, each with its value, its default, its description, and the line that sets it, in a tab beside the file. A value the file sets can be changed there, and the change is made in `ascribe.toml`, unsaved. See [Project Settings](../editor/settings.md#project-settings). |
| **Ascribe: Show Server Output** | Opens the log of the active file's project. When no file of a project is active and the workspace has several projects, it asks which, showing whether each one's server is running. |
| **Ascribe: Restart Language Server** | Stops and starts every project's server that has started, including one that stopped after crashing, and forgets earlier crashes. A server that hasn't started stays off until it's needed; when none has, the command says so. It also picks up `ascribe.toml` files added or deleted. |
| **Ascribe: Switch Project** {available="ascribe 0.4.0"} | Lists the workspace's projects, the sidebar's first, each with its folder and its server's state, and shows the one you choose in the sidebar, starting its server, until a file of another project is active. Shown while the workspace has several projects. See [Switch Project](../editor/sidebar.md#switch-project). |
