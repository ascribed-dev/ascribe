**Rules.** No two terms or aliases may be the same text (compared ignoring case when either is case-insensitive; `model-glossary-duplicate-term`). The `link` file MUST exist and not be a fragment (`model-glossary-link`). Its `#id`, when it has one, MUST be a heading's id on that page, written in it or in a fragment it includes (`glossary-link-target-missing`); since ids depend on parsing, that's checked with the project, not by the loader.
