# The actions bar

`Ctrl+K A` (`Cmd+K A` on macOS) lists only what applies where the cursor is, with the syntax each action writes. In a numbered list, for example:

```text
Structure
  Make the list steps          @steps
  Mark where it's available    @available:
  Make the page one variant    variant:
  …
```

Fixes for problems at the cursor come first. An action that needs something, such as a page to link to or a dimension's values, asks for it in the same box, so you choose from the project instead of typing syntax.

Every action is also in the Command Palette, and under **Ascribe** in the editor's context menu.
