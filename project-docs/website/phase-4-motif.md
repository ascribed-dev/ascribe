# Phase 4: The gutter, and the mark in motion

Part of [The website, and the brand on everything else](README.md). Needs phase 2's layout.

## Goal

- **The gutter's change marks as the site's device:** a split bar on notes, as in board 11's mock.
- **The three states,** writing, changed, and reviewed, wherever the site shows them.
- **The mark in motion,** standing still for anyone who prefers reduced motion.

## Design

### The split bar

A note's left bar is drawn as two segments with the gutter's gap, in the note's color. It's a rule in `site.css` on the element library's notes, and the library's default stays one bar (decision 9). The markup doesn't change, so `tests/render/` doesn't either.

### The three states

- **Writing** is river with the cursor.
- **Changed** is river's split marks.
- **Reviewed** is moss.

Where the site already shows a change, in review's marks on a page in the site's preview, changed is river from phase 1. This phase adds "reviewed" as a state with its own token, if review has a place that shows a change as reviewed. If it has none, nothing is added for the sake of the motif.

### The motion

An animated SVG generated by `assets.ts` from the grids, so it's sharp at its size. It steps through the board's frames without easing, using CSS `steps()` inside the SVG:

1. The cursor after the a.
2. A blink.
3. The cursor stepping left a cell at a time into the margin, where it splits into the change marks.
4. The marks turning moss. Under `prefers-reduced-motion: reduce` it shows the changed state and holds still. It plays once, in the landing page's hero, where the mockup put it. It's not in the header, which is on every page.
