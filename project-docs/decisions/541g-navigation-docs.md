section: The docs and the site
---

**Navigation's docs are a feature folder, `docs/content/navigation/`, and Ascribe's own site takes its sidebar from `docs/ascribe.nav`, with no list of its own.** The folder has the reference for `ascribe.nav` and `nav-label` as its `index.md` and the how-to, "Put your pages in order", as `order.md`; the contract is `contracts/navigation.md`, beside `permalinks-list.md`; `command/project-files.md` lists the file; and the Astro reference documents `sidebar()` and `neighbors()`. The site has no `src/nav.ts`: `docs/ascribe.nav` lists every top section in the site's order, with a `label` where the default isn't the sidebar's and `pages` only where the default order isn't the site's, and the site's end-to-end test holds the published sidebar to `site/test/fixtures/sidebar.json`. _Why:_ navigation is a feature, so it gets a folder with every type of page about it (decision [#452](452-docs-by-feature.md)), and the docs are customer #1 (decision 15), so their site orders its pages as every site does. _From:_ the maintainer, on the navigation plan ([README](../navigation/README.md), decisions 16 and 25, and [phase 1](../navigation/phase-1-decisions.md), decision 8), 12 and 16 October 2026; built in [#575](https://github.com/ascribed-dev/ascribe/pull/575) and [#588](https://github.com/ascribed-dev/ascribe/pull/588), 17 October 2026; recorded when the plan closed, with [#541](https://github.com/ascribed-dev/ascribe/issues/541).
