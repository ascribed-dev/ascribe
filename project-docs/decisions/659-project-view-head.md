section: The binary
---

**Switch Project is offered in the Project view's title bar alone, and Pages and Content model lose it; the Project view has no badge; and the status bar menu keeps every entry it has, each doing what the Project view does.** This replaces where [decision #654a](654a-project-view.md) left Switch Project, in Pages' and Content model's title bars by [decision #544a](544a-sidebar-views.md); it stays in the Command Palette and the status bar menu, and in none of them with one project. The Project view's head switches the build you're looking at, which is the one `ChosenBuilds` choice the status bar's Switch Build and the preview's picker set, not a second one, and its Show Output and Restart are the status bar menu's, for the view's project. In Restricted Mode the view is shown, as This page is, with a sentence in place of the counts, Manage Workspace Trust, and every action off. _Why:_ the view is about the project, so choosing which project is its job; two badges in one sidebar compete, and This page's is the one an author acts on as they write; and the status bar is there with the sidebar closed, its menu the keyboard's quick route, so each job has one implementation and two ways to it, the view being the one that explains. _From:_ the maintainer, decisions 3, 4, and 5 of [the editor's next views](https://github.com/ascribed-dev/ascribe/blob/62bf76a9/project-docs/roadmap.md#decisions), on [the Project view proposal](https://github.com/ascribed-dev/ascribe/blob/62bf76a9/project-docs/proposals/project-view.md#settled), 20 October 2026; built in [#659](https://github.com/ascribed-dev/ascribe/issues/659).
