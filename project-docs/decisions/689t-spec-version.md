section: The language
---

**`spec` is a quoted string that exactly equals a version the processor implements: `"0.1"` for now.** Until 1.0, `"0.1"` names the draft, whose grammar and built-in vocabulary may grow ([decision #955](955-spec-draft-until-1-0.md)). Compatibility ranges are for when 0.2 exists (SPEC §11). _Why:_ there's one version, and compatibility ranges are revisited when 0.2 exists. _From:_ the content model contract's decisions, item 21 ([§26 of its validation rules](https://github.com/ascribed-dev/ascribe/blob/eb7e077/docs/content/contracts/content-model/validation.md#26-decisions)), 28 September 2026, as recommended there; a file of its own since [issue #689](https://github.com/ascribed-dev/ascribe/issues/689).
