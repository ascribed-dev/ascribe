section: The docs and the site
---

**`examples/astro-site` publishes Loom's API with Redoc 3.0.1, a pinned `devDependency` loaded on an Astro page at `/docs/api` with `disable-telemetry="true"`, and its end-to-end test follows a guide's two links into it, and a template's into Stoplight Elements 9.0.28.** Redoc 3 takes `#operation/getLoom` for its own address of the operation, rewrites the address to `#/looms/getloom`, and scrolls the operation's heading to the top of the viewport, for an operation under a tag with a space too; the test asserts the heading's place, not Redoc's own address, which is Redoc's to change. Without `disable-telemetry`, Redoc 3 sends usage traces to `otel.cloud.redocly.com`, and the test asserts it sends none. The page has a visually hidden title and a sentence linking the spec, emitted as a file rather than inlined, so a reader without JavaScript, and an agent's checks, find content on it. _Why:_ the plan's seam: if Redoc's address hadn't landed from a built site, the profile would have changed first. _From:_ [#917](https://github.com/ascribed-dev/ascribe/issues/917), [OpenAPI, phase 1](../openapi/phase-1-thread.md), 25 October 2026.
