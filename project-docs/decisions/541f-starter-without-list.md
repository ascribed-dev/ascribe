**`npx @ascribed/astro init` writes no list of the site's own: the starter's layout draws its sidebar and previous and next from the project's navigation.** It writes three files, the collection, the layout, and the page route, and runs no build, since there's no list to fill. The layout calls `sidebar(entries, { entry })` and `neighbors(entry, entries)`, and `examples/astro-site`'s layout is held to it by a test. A site with a `src/nav.ts` keeps it, passed as `nav` (decision [#537c](537c-sidebar-from-project.md)), and the navigation guide says how to move one over. _Why:_ a list in a new site's code fails its build each time a writer adds a page, which is what the project's navigation replaces. _From:_ the maintainer, on the navigation plan ([README](../navigation/README.md), decision 16), 12 October 2026; built in [#588](https://github.com/ascribed-dev/ascribe/pull/588), 17 October 2026; recorded when the plan closed, with [#541](https://github.com/ascribed-dev/ascribe/issues/541).
