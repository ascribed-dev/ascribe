section: The binary
---

**When a project's rules for agents run over their 4,000 characters, what an agent can read elsewhere is cut before the page types, and each type's name and purpose is the last thing cut.** In order: the memo sentences; each built-in directive's syntax, leaving its name and what the project declares for it (dimension values, note types, sources, its own targets for `@available`), with a pointer to the skill's directive reference; the sentences on summaries and the site output, which the skill says too; each page type's template, guide, and fields, leaving its name and what it's for. Only then are lines cut: the directives' first, then the page types', each with where the rest are. A widget's line stays whole, since only the project says what it is. This replaces the order in which the page types were cut first. _Why:_ a page names its type before anything else, so the types are what an agent needs before it writes one, and Ascribe's own `docs/AGENTS.md` listed none of its six, while keeping text the skill already carries. _From:_ Kyle, [#1002](https://github.com/ascribed-dev/ascribe/issues/1002) and [#1177](https://github.com/ascribed-dev/ascribe/issues/1177), 27 October 2026.
