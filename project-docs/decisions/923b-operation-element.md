section: The language
---

**The site output writes an `@operation` as `<ascribe-operation>`, element contract §11: attributes `api`, `method` in lowercase, `path`, `operation-id` when it has one, and `deprecated`, present and empty when it is, as `planned` is; and, inside, one line, an `<a href>` to the operation's address whose text is the plain output's line, then a `<span class="ascribe-operation-deprecated">(deprecated)</span>`.** It's one HTML block with no markdown inside, as `<ascribe-availability>` is, so `render_site_html` and the Astro plugin pass it through as written, and the render fixture `operation` holds both to it. The deprecation is words in the HTML, not CSS generated content, so a reader with no stylesheet, and a check that each line of the HTML is in the Markdown, find it; the library strikes the link through and colors the words with the deprecated state's color. A summary's line breaks are spaces, so a summary can't end the HTML block early. _Why:_ the element is a line linking to the reference, which reads as one with or without the element library, and a site styles it by method or deprecation through the attributes. _From:_ [#923](https://github.com/ascribed-dev/ascribe/issues/923), [OpenAPI, phase 7](../openapi/phase-7-embed.md), 25 October 2026.
