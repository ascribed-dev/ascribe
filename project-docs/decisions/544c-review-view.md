section: Review
---

**While review is on, a Review view lists the pages `ascribe diff` lists for the review's base, with the problems on them, and opens the branch's source changes in VS Code's diff.** The pages are the language server's, `ascribe/review/changes` for the base `ascribe/review/setBase` set, under Added, Changed, and Removed, each with its counts, what it changed through, and its open threads; choosing one opens it and its preview at its first change. **Problems on these pages** lists the errors and warnings VS Code has for the changed pages' files, with advice behind the view's eye toggle, whether the branch made them or not; it's the whole of a "changed by this branch" filter, and there's no other. The view's badge counts the unsent comments, and its title bar has **Submit Review…**, **Open Source Changes**, and **Stop Review**. **Open Source Changes** runs `vscode.changes` over each changed page's file and the files it changed through, and each page has a button for its own; the base side comes from the Git extension's `toGitUri` first, and where the Git extension is off or has no repository for the file, from `ascribe/review/baseFile`, which the server answers from the base's source index and the extension serves as `ascribe-base:` documents. A snippet's code file isn't among them, since a page names what it changed through by address. **Changed Pages** stays, for the keyboard and the preview's button. _Why:_ the view, its problems, and `ascribe diff` never disagree when they're one answer; the problems are in the place a reviewer already is; the Git extension is built in and on by default, and the diff editor takes a file's language from its URI, while the server's documents keep the diff working without it. _From:_ the maintainer, on the editor's views plan ([README](../editor-ui/README.md), decisions 6, 12, and 13) and its [proposal](../proposals/editor-ui.md#settled), settled 16 October 2026; shipped in [#553](https://github.com/ascribed-dev/ascribe/pull/553), 17 October 2026; recorded when the plan closed, with [#544](https://github.com/ascribed-dev/ascribe/issues/544).
