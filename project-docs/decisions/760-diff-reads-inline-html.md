**`ascribe diff` reads a block's inline HTML as a reader reads it: its tags and comments are left out of the block's text, and a `<br>` reads as a space, as in `ascribe search`'s reading and the plain output.** The text the report shows (`now_text` and `was_text`) and the words it marks change with it. A change only inside an HTML comment, or a tag's attributes, still marks the block as changed, since its fingerprint keeps the HTML as written, but with no words marked, as a change to only a link's target already is. _Why:_ `diff` compares text "as a reader sees it", and a reader never sees a comment or a tag; and [the Search plan](https://github.com/ascribed-dev/ascribe/blob/62bf76a9/project-docs/search/README.md)'s decision 1 moves `diff`'s text onto the reading search matches, which can't keep the markup without search matching it. _From:_ the maintainer, choosing to fix `diff` first, in a pull request of its own, when phase 6 of the Search plan ([#646](https://github.com/ascribed-dev/ascribe/issues/646)) found the difference, 21 October 2026.
