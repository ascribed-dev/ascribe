section: The binary
---

**`ascribe model --format json` gives each page type's field a `declared`: `frontmatter` for a field of `[frontmatter]`, `type` for one of the type's own `frontmatter`, and `implicit` for the required string `title` neither declares.** It's a field added, so `schema_version` stays 3 (the JSON reports contract: fields are added without a new version); an object's fields have none, since they're declared wherever the field holding them is. The text says the same after each field's type, as `from [frontmatter]`, `own`, or `implicit`, when a type's fields aren't all its own, so a project without `[frontmatter]` reads as it did; the rules for agents don't say it, since an agent writing a page needs a field's type, not its table. _Why:_ a type's field replaces `[frontmatter]`'s whole (decision #807), so a copy that drifts from the shared one is only seen where the field's table is shown; the editor's hover shows it to a person, and the JSON to a tool or an agent. _From:_ the maintainer, 21 October 2026, Settled 3 of the [proposal for a shorter content model](../proposals/shorter-content-model.md#settled), which says the hover and `ascribe model` say which table declared a field; built in [issue #808](https://github.com/ascribed-dev/ascribe/issues/808).
