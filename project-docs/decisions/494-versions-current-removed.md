section: The binary
---

**`[versions]` has `scheme` alone: `current` is removed, and `[releases]` says which versions exist, for each target.** A project that sets `[versions] current` gets an error that names `[releases]`. `availability-left-behind` (ASC172) compares each target's versions with that target's current line, the newest in its `live` list, where it read `current`, and reports nothing for a target with no `[releases]`; the rest of decision 67 stands. `docs/ascribe.toml` and `site/home/ascribe.toml` declare `[releases.ascribe]` in its place, and RELEASING.md's step moves the list. The [Versions plan](https://github.com/ascribed-dev/ascribe/blob/395fe80d/project-docs/versions/README.md)'s phase 3 builds it. This amends decision 67. _Why:_ `current` was one version for every target, a second home for the fact the list holds, and one that can't say two products are at different versions; it shipped in 0.3.0, so a project that sets it gets an error rather than a warning first, which the maintainer chose knowing that on #505, and decision 67's own reason expected a table per target. _From:_ the maintainer, taking the recommendation on [#494](https://github.com/ascribed-dev/ascribe/issues/494#issuecomment-6195368949), 15 October 2026.
