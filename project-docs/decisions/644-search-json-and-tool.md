section: The binary
---

**`ascribe search --format json` writes a document of its own, and `ascribe mcp` offers it as `ascribe_search`; both are contracts.** The document is `schemas/search.schema.json`, generated from `ascribe_query::Searched`, at `schema_version` 1, under decision 52's rules: `query`, `builds` (searched), `places`, `pages_matched`, `total`, and decision 51's `shown`, `truncated`, and `next_command`, the list cut at 500 places unless `--limit` says otherwise. Each place is `file` (from the project root), `line`, `column` (in Unicode characters), `end_line` (the last line a snippet shows, for its code that can't be lined up with its file, and otherwise null), `in` (`title`, `description`, `heading`, `text`, `table`, `code`, or `phrase`, a phrase's value at its line in `ascribe.toml`), `text` (the block as a reader reads it, whole), `match` (its first character and the one after its last, in characters of `text`), `through` (each `{"phrase": key}`, `{"title": "page.md#id"}`, or `{"code": address}`, in order), `arm`, `pages` (at most three, each `page`, `title`, `heading`, `id`, and `builds`), `pages_total` (for a phrase, the places that use it), and `refs_command` (for a phrase, and for a fragment's line whose `pages` were cut). With `--summary`, `places` is empty and `pages` lists each page and its count of `places`, with `shown` and `truncated` counting pages; without it, `pages` is null. When nothing matched, `source_places` gives the first three places the source writes the words, each `file` and `line`, and `not_searched_builds` the builds not searched that publish them. The exit codes are `0` when something matched, `1` when nothing did, and `2` when it couldn't run. The tool takes the command's arguments under their names, `query`, `paths`, `build`, `type`, `case`, `word`, `summary`, and `limit`, with `project` (a file or folder in the project, when no `paths` are given) and `response_format`, concise by default, and returns what the command writes. The server keeps each build's readings with the project it has loaded, and drops them with it. A place in a fragment has no `{"include": …}` in `through`, which the search plan's phase file listed: the place is the fragment's own line, so nothing between the line and the words is an include, and `pages` with `refs_command` say which pages show it. _Why:_ an agent about to write a page asks where the docs already say it, and reads the answer as JSON or through the tools; decision 56 makes the tools' names and arguments a contract, and the search plan's decisions 5, 13, and 14 settle the command's. _From:_ the [search plan](../search/README.md), its decisions 5, 13, 14, and 17, and [phase 4](../search/phase-4-agents.md), 20 October 2026; built in [#644](https://github.com/ascribed-dev/ascribe/issues/644).
