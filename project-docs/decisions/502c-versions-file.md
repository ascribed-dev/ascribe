section: The binary
---

**The lines of every versioned build share one file, `<output-dir>/_ascribe/versions.json`, the one exception to nothing being shared between builds: each build's lines, and the lines that publish each page, at which route.** It's owned through the folder's own manifest, `_ascribe/manifest.json`, in a build's manifest format, so the store's ownership rules hold for it as for an emitter root; an `_ascribe` folder with files and no manifest isn't Ascribe's, and is left alone. Every `ascribe build` of a project with `[releases]` writes it, for every versioned build, whichever builds were asked for; the first build of a project without the table removes it, then the manifest, then the folder when nothing else is in it. Its top is `version`, 1, and `builds`, keyed by a versioned build's declared name, each with `target`, `label` (the target's label, or its name), `lines`, and `pages`. `lines` are the live lines newest first, then the archived ones newest first: a live line has `line` as `[releases.<target>]` writes it, `status` (`current` or `live`), `build`, `base`, and `ends` when the project gives it; an archived line has `status: "archived"`, `url` and `ended` when the project gives them, and no `build` or `base`. A planned line isn't in the file, which narrows the plan's decision 28: it listed `planned` among the statuses, and a planned line has no output to give. `pages` is keyed by a page's source path from the content root, each with `lines`, its route in each line that publishes it, and `replaces` and `replaced-by` when the other page is in the file too, `replaced-by` naming the first by path when more than one page replaces it; `replaces` isn't in the site output's frontmatter. A later version adds keys and changes none. The [output layout contract](../../docs/content/contracts/output-layout.md)'s §1.5 has the format. _Why:_ a line's output can't know the others while builds are independent, and a site, Astro or not, needs a banner and a page's lines from one place; a site needs the pair of pages that replace each other, not each page's key, and the file already holds every line's pages. _From:_ the maintainer, on the [versions plan](https://github.com/ascribed-dev/ascribe/blob/395fe80d/project-docs/versions/README.md), decisions 11, 28, 43, and 53, 10 to 16 October 2026 (28 on [#494](https://github.com/ascribed-dev/ascribe/issues/494#issuecomment-6195368949); 43 confirmed with [#507](https://github.com/ascribed-dev/ascribe/pull/507), and 53 with [#515](https://github.com/ascribed-dev/ascribe/pull/515)); recorded when the plan closed, with [#502](https://github.com/ascribed-dev/ascribe/issues/502).
