section: The npm packages
---

**Bryo Studio is named as Ascribe's maker, everywhere but the VS Code Marketplace publisher, which stays `Ascribe`.** Every npm package's `author`, and the plugin's author and its marketplace's owner, are Bryo Studio, `https://bryostudio.com`, the maker in `design/words.toml`, which `scripts/design/words.test.ts` compares. The extension's id stays `Ascribe.ascribe-vscode`. _Why:_ Ascribe is a product, not an organization. A Marketplace publisher can't be renamed, and a new one means a new listing, a new identity for the release workflow, and every install command changed, for a name a reader rarely sees. _From:_ the maintainer, 21 and 22 October 2026, in [the story](../brand/story.md); [the website plan](https://github.com/ascribed-dev/ascribe/blob/58afc492/project-docs/website/README.md#decisions), decisions 13 and 14, carried out in #815.
