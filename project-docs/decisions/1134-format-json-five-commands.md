section: The binary
---

**`sources fetch`, `templates list`, `vale eject`, `agents sync`, and `agents prompt` take `--format json`, each writing one document of its own at `schema_version` 1, and the JSON report contract gives `ascribe agents` a page of its own.** `sources fetch` writes its `FetchReport`; `templates list` the set's source and each template's `name` and `summary`; `vale eject` the `preset` and the files `written`; `agents sync` each file's `path`, `changed`, and `read_by`, with its `notes`, `unread`, and `mcp_settings`, and with `--check` too; `agents prompt` the prompt's `name` and `text`, or with `--list` every prompt and its arguments. Each takes `concise` as an alias of `text`. `agents index` moves to the new page, [json-reports/agents.md](../../docs/content/contracts/json-reports/agents.md), from the questions page. _Why:_ decision [#965](965-cli-conventions.md) has every command that doesn't only print a file take `--format json`, and these five were its exceptions; the questions page was already past the length an agent reads in one piece. _From:_ Kyle, [#1134](https://github.com/ascribed-dev/ascribe/issues/1134), as triage split it, in [#1187](https://github.com/ascribed-dev/ascribe/pull/1187), 27 October 2026.
