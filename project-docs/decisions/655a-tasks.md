section: The binary
---

**Build and Sync Agent Files are tasks of the extension's `ascribe` type: each runs the binary the project's server runs, in the terminal, in the project's folder, with `--config` naming its `ascribe.toml` when the project isn't the workspace folder, and with no problem matcher.** They're offered in the Project view's Actions and in **Tasks: Run Task**, and neither is offered or resolved in Restricted Mode. `tasks.json` names one by `task` (`build` or `syncAgentFiles`) and `project` (the project's folder relative to the workspace folder, left out for the workspace folder's own); those two property names are the implementation's, for the maintainer's review in [#735](https://github.com/ascribed-dev/ascribe/pull/735). Observe Examples isn't one of them yet: where it runs and how its question is asked wait on a decision of their own. _Why:_ a task shows what ran, as CI would, and can be bound to a key; and with no problem matcher, the Problems panel stays Check Every Build's and the editor's, so the two never disagree. _From:_ the maintainer, on [the Project view proposal](../proposals/project-view.md#actions) and [the editor's next views](../roadmap.md), 20 October 2026; built in [#655](https://github.com/ascribed-dev/ascribe/issues/655).
