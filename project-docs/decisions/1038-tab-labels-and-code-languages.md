section: The npm packages
---

**A tab's label is text in the site output, and a highlighted code block keeps its language as a class on its `<code>`, element contract §3 and site-render contract §5.2.** Each `<ascribe-tab>` starts with its label as a paragraph of its own, `<p class="ascribe-tab-label">npm</p>`, before its content; the `label` attribute stays, for the script's buttons. Without the script the paragraph introduces the tab, as the CSS generated label did, which it replaces; with it, the script gives the paragraph `aria-hidden="true"` and the stylesheet hides it from sight, but not with `display: none`, so a screen reader hears the label once, from the tab's button, and a reader that takes the rendered page's text still finds it. `@ascribed/astro` adds a Shiki transformer that gives a highlighted block's `<code>` the class `language-<lang>`, as CommonMark renders it before highlighting, whatever `codeTitles` is; a block highlighted as `plaintext` gets none. The label paragraph has no source anchor: the tab's anchor says where it is. _Why:_ many agents only ever read a page's HTML, through an HTML-to-text or HTML-to-Markdown converter, which reads neither an attribute nor CSS generated content, nor Shiki's `data-language`: they read a group of tabs as unnamed code blocks, and fences with no language. Both changes are additive for sites. _From:_ Kyle, on [issue #1038](https://github.com/ascribed-dev/ascribe/issues/1038#issuecomment-6418264973), 26 October 2026.
