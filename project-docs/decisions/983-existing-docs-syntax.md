---
section: The docs and the site
---

**The guide to bringing existing docs to Ascribe shows the syntax it rewrites, not the tools it comes from.** Each form it handles (`:::note`, `!!! note`, `> [!NOTE]`, wiki-style and `.html` links, heading ids in braces) is shown beside what Ascribe writes instead, and no other tool is named, so the site keeps other tools off it, as decision 4 of the product story does. _Why:_ a writer bringing docs over recognizes their own syntax faster than a product's name, and the docs stay off other tools. _From:_ Kyle, [#983](https://github.com/ascribed-dev/ascribe/issues/983#issuecomment-6418249169), 26 October 2026.
