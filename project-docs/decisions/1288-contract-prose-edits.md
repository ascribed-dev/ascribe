section: The docs and the site
---

**A contract page takes the docs review's prose fixes where they change wording and no rule.** The pages under `docs/content/contracts/` open with a sentence saying what the page covers, write "Markdown" and "folder", end a bullet with a period, and may put a long enumeration in a list, as the review's prose issues ask of every page ([#1281](https://github.com/ascribed-dev/ascribe/issues/1281), [#1283](https://github.com/ascribed-dev/ascribe/issues/1283), [#1285](https://github.com/ascribed-dev/ascribe/issues/1285), [#1255](https://github.com/ascribed-dev/ascribe/issues/1255)). The numbered sections, their ids, and what each rule requires stay as they were, and a change to any of those is still its own decision. A pull request that makes such an edit says so in its description, and the reviewer holds it to this. _Why:_ the contracts are read by implementers and change only by a decision, but an opening that points instead of saying, or "markdown" beside "Markdown", is a fault of the prose and not a rule, and leaving the contracts out of the review's fixes would make them the only pages that keep the patterns the review found. _From:_ the maintainer, asking for the deslop pass over the docs in the Claude Code session that opened the pull request for the review's prose issues, 4 November 2026.
