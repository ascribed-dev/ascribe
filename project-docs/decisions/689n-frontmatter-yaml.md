section: The language
---

**Frontmatter is read with the YAML 1.2 core schema, and a `date` field accepts a `YYYY-MM-DD` scalar, quoted or not.** So `yes` is a string and `3.10` a number. _Why:_ none was recorded beyond the examples, `yes` a string and `3.10` a number, which are what an author who writes them means. _From:_ the content model contract's decisions, item 15 ([§26 of its validation rules](https://github.com/ascribed-dev/ascribe/blob/eb7e077/docs/content/contracts/content-model/validation.md#26-decisions)), 28 September 2026, as recommended there; a file of its own since [issue #689](https://github.com/ascribed-dev/ascribe/issues/689).
