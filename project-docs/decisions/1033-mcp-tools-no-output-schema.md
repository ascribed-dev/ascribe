section: The binary
---

**The tools of `ascribe mcp` give no output schema, and `tools/list` is held to 25 KB.** Each tool's description ends by naming its command and the [JSON report contract](../../docs/content/contracts/json-reports.md), at its permalink `https://ascribed-dev.com/go/json-reports/`, which has the command's schema; each tool's `structuredContent` is still its command's JSON document (decision 56). A test in `crates/ascribe-cli/tests/all/mcp.rs` fails when `tools/list` is over its budget, so a new tool or a longer description spends from it on purpose. _Why:_ the output schemas were 73 KB of a 92 KB list, which a host can give the model before its first call in every session, and hosts that don't still send and parse them. Keeping full schemas for the three tools whose results an agent reads field by field (`ascribe_explain`, `ascribe_outline`, `ascribe_link`) would put the list near 29 KB, and keeping only top-level properties would give a second, shorter account of each document that could disagree with the contract. _From:_ [#1033](https://github.com/ascribed-dev/ascribe/issues/1033), finding F5 of the agent-reader review of the docs, 26 October 2026.
