section: The binary
---

**A prompt that names a page lists the memo files about it, a line each, and the rules tell an agent to read a memo before changing what it's about; no prompt or rule carries a memo's text.** The `fix` prompt (`ascribe agents prompt fix`, `ascribe check --format prompt`, and the editor's **Prompt agent**) lists the memos about each page it names, after the problems and under a heading of its own, each line with the memo's path, its `about`, and its state when it isn't placed. The `review` prompt (`ascribe diff --format prompt`, the HTML report's Copy prompt, and the editor's prompts about changes) lists each memo on a changed block, on the section a change is in, outdated ones included, or on the page as a whole, and asks the agent to check the change still agrees with it; a memo whose quote puts it on another block of the section isn't listed, and a removed block counts as where it was. A personal memo is listed on the machine that has it, marked personal. Each list stops at ten and gives the `ascribe outline` command for the rest. A prompt names a memo by its path and `about`, not its first line, as [#566](https://github.com/ascribed-dev/ascribe/pull/566) shipped it; `ascribe outline` gives the first line. The rules `ascribe agents sync` writes have a sentence when a page has a `@memo`, to read a block's memo before changing the block and keep the two together, and another when `memos/` has a memo file, that `ascribe outline <page>` lists the memo files about a page; personal memos don't count, so the rules are the same on every machine, and when the rules are over their budget the two sentences are cut first, together. The `new-page` prompt's memos are [decision #536e](536e-template-instructions.md)'s. _Why:_ an agent most needs to know why a page is written the way it is and can't work it out, and a reason handed over with the page does more than the same reason anywhere else; a path costs a line, where a memo's text pasted in would make every prompt pay for a long memo. _From:_ the maintainer, on the memos plan ([README](../memos/README.md), decision 17, [phase 3](../memos/phase-3-surfaces.md)'s rule, and [phase 7](../memos/phase-7-agents.md)), 14 October 2026, as [#552](https://github.com/ascribed-dev/ascribe/pull/552) and [#566](https://github.com/ascribed-dev/ascribe/pull/566) shipped them on 16 and 17 October 2026; recorded when the plan closed, with [#536](https://github.com/ascribed-dev/ascribe/issues/536).
