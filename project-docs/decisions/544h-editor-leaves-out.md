section: The binary
---

**The editor has no language status item, no count lens on headings, no drop or paste handler of Ascribe's own, no document symbols from the language server, and no chat participant.** The status bar item already shows the project, the build, and the server's state. This page counts what reaches the heading at the cursor. Dropping and pasting files and images into a page stay VS Code's Markdown extension's, which also gives pages their Outline; a drop handler that asks for alt text, as **Insert an image** does, comes only if what VS Code's drop writes fails `ascribe check`, a check by hand the [brainstorm](../brainstorm.md#21-the-editors-views-whats-left) keeps. Document symbols from the server would give VS Code a second Outline beside the Markdown extension's, and they wait until someone using another editor asks for them. Agents in chat have the MCP server, the extension's tools, and the skill. _Why:_ each repeats something that's already shown or already works. _From:_ the maintainer, on the editor's views plan ([README](https://github.com/ascribed-dev/ascribe/blob/395fe80d/project-docs/editor-ui/README.md), decisions 7 and 9) and its [proposal](https://github.com/ascribed-dev/ascribe/blob/395fe80d/project-docs/proposals/editor-ui.md#settled), with the chat participant from the proposal's [What this leaves out](https://github.com/ascribed-dev/ascribe/blob/395fe80d/project-docs/proposals/editor-ui.md#what-this-leaves-out), settled 16 October 2026; recorded when the plan closed, with [#544](https://github.com/ascribed-dev/ascribe/issues/544).
