---
section: The docs and the site
---

**The docs are grouped by feature: a folder is a feature or a subject, and every type of page about it is in that folder.** Review's how-to, its troubleshooting, and its command's reference are together in `review/`, and the sidebar has a group for each folder. A page's type is what it declares in its frontmatter (decision #450), which a section can order or label by, and never where it's filed. The contracts stay one section, since they're for a different reader, someone building on Ascribe's outputs. _Why:_ a reader looking into a feature wants everything about it in one place, and shouldn't go to another part of the site for related content. Grouping by content type ships the docs' own filing system to people who don't care about it. _From:_ the maintainer, 12 October 2026, on finding the sidebar grouped by type after the docs took the page types.
