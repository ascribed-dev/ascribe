---
section: The language
---

**`nav-label` is a reserved frontmatter key: a page's label wherever it's an entry in a list.** It's a string on one line, read as the page's `title` is, with code spans where `title` sets `inline = "code"` and phrases where `title` takes them. A content type can't declare it, and a fragment can't use it. It's the page's `label` in `nav.json` and `ascribe model`, in a sidebar, in an archive's sidebar, and in previous and next; a section's default label stays its own page's title, and the page keeps its title everywhere else, `llms.txt` included. A value that isn't a string on one line is `frontmatter-type-mismatch`, and one longer than the title, each as plain text, is advice, `nav-label-long` (ASC237). _Why:_ a menu needs a short name and a page's heading a full one, and an agent looks for a page by its title. _From:_ the maintainer, on the navigation plan ([phase 1](../navigation/phase-1-decisions.md), decision 6; [README](../navigation/README.md) decisions 11 and 23), 16 October 2026; recorded with [#539](https://github.com/ascribed-dev/ascribe/issues/539).
