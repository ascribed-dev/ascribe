section: The binary
---

**The Ascribe sidebar has four views, in order: Review while review is on, This page, Pages, and Content model; there's no Projects view, and a workspace with two or more projects switches with Ascribe: Switch Project.** Pages is always shown, so the container is there in a workspace with no project, and it holds the welcome messages for Restricted Mode and for a workspace with no project; This page and Content model are shown while `ascribe.active`. When the sidebar's project's server fails, Pages and Content model say so with **Show Output** and **Restart**, as welcome content under `ascribe.sidebar.failed`, since a view's message can't hold a link; the two links run commands kept out of the palette, which act on the sidebar's project. Switch Project is offered only while `ascribe.multipleProjects`, which the extension sets beside `ascribe.active` each time projects are found, left out by `ascribe.projects.exclude`, or deleted: in the Command Palette, in Pages' and Content model's title bars, and in the status bar item's menu. It lists every project, the sidebar's first and marked, each with its folder, its server's state, and its binary, with Show Output and Restart as buttons; choosing one shows it in the sidebar and starts its server. With one project, Show Output and Restart stay in the status bar item's menu. The sidebar follows the active file, after a switch too: a switch is a jump, not a pin, and only a file of another project becoming active moves the sidebar off it. The views are native trees; whether any should be a webview, This page first, is a question for after they're in use. _Why:_ more than one project is supported but isn't the common case, and the status bar already names the one project; a pin would be state nothing on screen shows; Pages being always shown keeps the container where the welcome messages say how to start; the views' rows are labels and descriptions, which a tree draws with VS Code's theming and keyboard. _From:_ the maintainer, on the editor's views plan ([README](https://github.com/ascribed-dev/ascribe/blob/395fe80d/project-docs/editor-ui/README.md), decisions 1, 2, 4, and 10) and its [proposal](https://github.com/ascribed-dev/ascribe/blob/395fe80d/project-docs/proposals/editor-ui.md#settled), settled 16 October 2026; the failed views' links as welcome content from [#590](https://github.com/ascribed-dev/ascribe/pull/590), 17 October 2026; recorded when the plan closed, with [#544](https://github.com/ascribed-dev/ascribe/issues/544).
