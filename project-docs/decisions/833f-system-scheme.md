section: The website

**The site follows the reader's system scheme, light or dark, and has no theme picker.** _Why:_ both schemes are designed and checked, and a picker is a control and a stored setting for a choice the system already makes. _From:_ the maintainer, 21 October 2026; [the website plan](https://github.com/ascribed-dev/ascribe/blob/58afc492/project-docs/website/README.md#decisions), decision 7.
