**A retired address gets a page saying why, in `_ascribe/gone/` under its build's base path, which the host serves at the address with a 404.** `redirects.json`'s `gone[]` gains `page`, the same for a page's address and its Markdown version's; Netlify's `_redirects` gains `<path> <page> 404` for each, after the pairs. `page` is the base path, `_ascribe/gone/`, and the address from the base path, since a site generator serves the build under its base path, as Astro's `base` does. `@ascribed/astro` adds a route, `<base path>_ascribe/gone/[...address]`, for each base path whose build lists one, failing the build when it isn't under Astro's `base`, as permalinks do, building a page for each with the reason as text, a link to its project's root, and `noindex`, and leaves the pages out of the sitemap. The markup is the integration's; another site generator reads `gone` and writes its own. _Why:_ a 404 tells a search engine to drop the address, and a page saying why tells the reader; serving it with a rewrite keeps the address the reader asked for. _From:_ [#906](https://github.com/ascribed-dev/ascribe/issues/906), [redirects, phase 2](https://github.com/ascribed-dev/ascribe/blob/9162c25a/project-docs/redirects/phase-2-decisions.md), task 5, 25 October 2026.
