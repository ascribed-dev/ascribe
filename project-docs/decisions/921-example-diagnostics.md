section: The language
---

**A marked example's checks are four rows of SPEC §8.2, under "Examples", each file level and reported in the file the block is written in: `example-schema-mismatch` (ASC276, error) for each disagreement, `example-not-json` (ASC277, error), `example-body-missing` (ASC278, error), and `example-schema-unsupported` (ASC279, advice); the marker's link is a link, checked by the link rules, and compiles to nothing.** A disagreement's message says what the example has and what the body's schema says instead, "`name` is a number; the request body of `createUser` says it's a string", at the value, at a property's key when the schema doesn't allow it, and at its object's opening brace when a required one is missing; a value is named by its path, `address.city` or `tags[0]`, or "the example" for the whole block. A failed `anyOf` or `oneOf` is narrowed to the one alternative of the value's type, and when every alternative is of another type, as with a translated `nullable`, it's one wrong type naming them all. `example-not-json` is at where `serde_json` stopped, or at the marker for a block that isn't a `json` block. `example-body-missing` is at the marker, for a request body the operation doesn't take, a response with no status, a status it has no response for or whose response has no body, a media type it doesn't have, no JSON one, or more than one with none named, and for a marker whose link isn't to an operation; a link to an operation the spec doesn't have is `link-operation-missing` alone. `example-schema-unsupported` is at the marker, once for each pattern left out and once for a `$ref` into another file, which leaves the example unchecked. A status is matched without case, so `2xx` names `2XX`. The diagnostics are rows rather than an area's quality checks, so none is configurable: an example that disagrees with the API is wrong the way a broken link is. _Why:_ decision [#920](920-example-marker.md) made them SPEC §8.2's rows, and the registry gives a row no area; the places are the ones the spike found every disagreement has. _From:_ [#921](https://github.com/ascribed-dev/ascribe/issues/921), [OpenAPI, phase 5](../openapi/phase-5-examples.md), 25 October 2026.
