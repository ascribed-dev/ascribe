section: The language
---

**A type that names neither `template` nor `guide` takes both from the `templates.lock` in a project's `templates/`, when the lock records a template under the type's name, and `ascribe templates eject` into `templates/` stops writing the two keys.** It amends the page templates plan's [decisions 7 and 14](https://github.com/ascribed-dev/ascribe/blob/180eee83/project-docs/page-templates/README.md#decisions), which had a type name its template and its guide: the keys stay, for a project without the lock and a template written by hand, and a type that sets either keeps what it sets and takes nothing from the lock. Of an entry's `files`, the one ending `.guide.md` is the guide and the other the template, and its `ascribe-files` follow the guide, as `templates status` already reads them. The lock is read through `FileSystem` when the model is loaded with the project's files (`ascribe_check::type_files::from_lock`, which `load_model` calls), and a file it gives is held to the plan's decision 26 rules; a problem with one is the type's error, `model-type-template` with the variant `lock`, at the type's `[types.<name>]` key, since `ascribe.toml` has no path to point at. A lock that isn't there, or isn't of the version eject writes, gives nothing, and `templates status` reports it. Only `templates/` is looked in, so `eject --to` another folder still names the two keys, and a type kept there still gets them; in `templates/`, a type kept is left untouched, `ascribe.toml` isn't written when nothing in it changed, and `written` leaves it out. `ascribe model`'s `template` and `guide` are the type's, wherever they came from. The language server loads the model again when the lock changes, and its hover on a type's name in `ascribe.toml` says where its template comes from. _Why:_ every type eject wrote repeated two lines that the lock beside its files already says, so the docs' five set types were mostly paths. _From:_ piece 2 of [the shorter content model](https://github.com/ascribed-dev/ascribe/blob/bb56bfb3/project-docs/proposals/shorter-content-model.md#2-a-types-template-from-the-lock), made the maintainer's issue [#809](https://github.com/ascribed-dev/ascribe/issues/809), 22 October 2026.
