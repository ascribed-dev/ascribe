section: The binary
---

**Project Settings adds a setting the file leaves out, resets one with `null`, and sets a check's level and limit as the settings of `checks.<check>`.** It widens decision [#658](658-project-settings.md), whose tab changed only a value the file sets. `ascribe/settings` answers every simple setting of the tables a project doesn't name parts of, leaving out the items of a list such as `[[intended]]`'s, and every configurable check of the diagnostics registry, with its `when` as what it reports, its own level, the level the file sets, and, for `page-size`, `image-large`, and `memo-long`, its `limit` and the limit's default: the ones the file names first, then the rest, each in the diagnostics reference's order (decision 7 of [the editor's next views](../roadmap.md#decisions)). `setSetting` adds a value the file leaves out after its table's last entry, or adds the table at the end of the file, and a top-level one before the first table; and with `value: null` it takes the setting's line out, with the comment lines directly above it and touching it, and leaves a comment with a blank line before the key (decision 8, which `ModelFile::remove_entry` keeps for every action that removes an entry). A check is the table `checks.<check>`, with the keys `level` and `limit`, set in the form the file writes it: a level alone, which becomes an inline table to take a limit; an inline table, rewritten with its other keys; or a `[checks.<check>]` table, whose lines are set, added, and removed as a setting's are. A check the file doesn't name gets `<check> = "<level>"` in `[checks]`, or a `[checks.<check>]` table for a limit, or when the file has no `[checks]` table to add to. _Why:_ one action for set, add, and reset keeps the one rule of decision #658, that an edit is refused for any version but the one the tab drew, in one place; and a check's level and limit are keys of its table in the loader already, so naming them so gives the tab nothing to translate. _From:_ the [Project Settings proposal](../proposals/project-settings.md#settled), settled by the maintainer, and [the editor's next views](../roadmap.md#track-s-project-settings), 20 October 2026; built in [#660](https://github.com/ascribed-dev/ascribe/issues/660).
