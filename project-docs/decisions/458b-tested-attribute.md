section: The language
---

**A tested example's code block carries its environment alone in a `tested` attribute of its info string, and "Tested with" comes from the stylesheet.** It looks like `tested="Node 24.9.0 and TypeScript 5.9.2 on Linux"`, beside `title="…"`, and reaches both renderers the way a title does (SPEC §4.8). A block with a tested line and no title still gets a caption; a block with both has the title, then the tested line. The plain output writes the full sentence in English, on a line under the block, since nothing styles it. _Why:_ a site translates "Tested with" once, as it does the availability element's "Available:", and with no stylesheet the caption still reads as a fact about the block. The finished sentence would put English in every site's markup, and an attribute for each fact would turn names a project chose into attribute names and leave both renderers assembling a sentence. _From:_ Kyle, on [issue #458](https://github.com/ascribed-dev/ascribe/issues/458), taking [phase 1](https://github.com/ascribed-dev/ascribe/blob/180eee83/project-docs/tested-examples/phase-1-decisions.md)'s recommendation, 13 October 2026.
