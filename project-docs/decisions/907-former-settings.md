section: The language
---

**A routing setting changed is one `address-lost` warning, and `[former]` keeps every address it moved (SPEC §7.10).** The comparison adds each name a build answers to under the permalinks' path, and each `llms.txt` file, to each page's address, its Markdown version's, and each explicit id's. When the same sources publish under another `base-path` or permalinks' path, or `agents` went from on to off, the addresses moved are `address-lost`'s settings message, `{changes}, so {moved}`, naming each setting with its old and new values and how many addresses moved, of them how many permalinks, in place of a warning for each source; a page lost in the same change is still its own. A build of the base that's gone, when a build only the working tree has publishes more than half of its pages, is that build renamed, a change of the same message, compared with the new one. The message's one fix, which is safe, writes each old value into `[former]`, the newest last: the base path, the permalinks' path (unless both are the default, `go/` under the base path, which moves with `base-path`), `agents = [true]`, and the build's old name under `builds`, flat. A change `[former]` records accounts for what it moved, and `builds` matches the base's build with the new name. The build, from the file alone, forwards under each former base path every page's address, its Markdown version's, each `llms.txt` file's, each `[moved]` and `[retired]` key's, and each permalink's while `permalink-path` is the default; under each former `permalink-path`, each permalink's; and with `agents = [true]` and `agents` off, each Markdown version to its page and each `llms.txt` file to the page at the base path. Each leads to today's address, so a second change composes with the first. `redirects.json`'s `entry` for such a pair is `former.base-path`, `former.permalink-path`, or `former.agents` (output-layout contract §1.8). A permalink or `llms.txt` file lost otherwise isn't compared: a permalink's name is `ascribe.permalinks`' to keep, and `llms.txt` has no source. _Why:_ in the tabletop, a setting changed ended in every address a silent 404, and the setting's change is the decision, so recording it is safe and one warning says it once; forwarding to today's address keeps every pair one step. _From:_ [#907](https://github.com/ascribed-dev/ascribe/issues/907), [redirects, phase 3](https://github.com/ascribed-dev/ascribe/blob/9162c25a/project-docs/redirects/phase-3-settings.md), on [decision #904](904-redirects-formats.md), 25 October 2026.
