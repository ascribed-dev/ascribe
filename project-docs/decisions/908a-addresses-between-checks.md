section: The binary
---

**An editor's language server compares the addresses with the base's between checks and sends what it found as `ascribe/addresses`, never as a page's diagnostics, and the Project view counts it in a Health group of its own, Against the base.** The server keeps the base's addresses keyed by the base commit and Ascribe's version, and compares after a load, a save, a change on disk, or an edit to `ascribe.addresses`, debounced, never as a page is typed. The notification has the file's URI (`null` without one), the base, the count of pages lost, and the problems at the file; the extension shows them in Check Every Build's collection at `ascribe.addresses`, in place of the last check's there, and a check replaces them in turn. The group sits after Every build, current while the server runs, so a lost address counts while Every build is out of date. _Why:_ the problems are the project's, as Check Every Build's are, and Every build goes out of date on any change, which would hide the count the moment a page is deleted (README decision 8). _From:_ [#908](https://github.com/ascribed-dev/ascribe/issues/908), [redirects, phase 4](https://github.com/ascribed-dev/ascribe/blob/9162c25a/project-docs/redirects/phase-4-editor.md), 25 October 2026.
