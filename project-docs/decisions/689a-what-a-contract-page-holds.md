section: The docs and the site
---

**A contract page holds what's normative and its own; the reference holds the explanation, and no `MUST`.** A contract page has the rules, stated with `MUST`; the file formats (`ascribe.lock`, `llms.txt`'s layout, the link cache's files); the rule tables; and the key tables, which it shares with the reference through the registry's generated fragments in `docs/content/_generated/`, never a hand-written one. It has no explanation, examples, or reasons. A reference page has the tables, the explanation, examples, and tasks, and no `MUST`. What both say alike is a fragment in `docs/content/_fragments/content-model/`, which carries no `MUST` either, so a rule is written on each page in its own words: with `MUST` and no reason in the contract, and with the reason in the reference. Each page links to its twin at the top. The decisions in the contract's §26 are files in this folder now, and the contract has no §26: items 1, 3 to 6, and 8 to 23 are decisions #689b to #689v, in order, and items 2 and 7 are [decision #450](450-page-type-key.md) and [decision #545a](545a-glossary-pages.md), which replaced them. This replaces what [decision #650](650-content-model-tables.md) said of the contract's own tables, and the part of decision 111 that gave the fragments the contract's `MUST`; the shared section numbers stay. `tests/conformance/tests/docs.rs` fails on a sentence written in both, a hand-written key table in either, or a `MUST` in the reference or its fragments. _Why:_ the two were parallel documents with the same titles, numbering, and tables, 10% to 28% of each page's sentences in its twin, and the fragments carried the contract's `MUST` into the reference ([the docs audit](../docs-audit.md#the-ascribetoml-reference-and-its-contract)); a key table written by hand in the contract would be a third home for each key. _From:_ decision 1 of [the docs cleanup plan](../docs-cleanup/README.md#decisions), Kyle, for its phase D17, [issue #689](https://github.com/ascribed-dev/ascribe/issues/689), 20 October 2026.
